[7.三数之和](https://leetcode.cn/problems/3sum/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

这道题比[[1.两数之和]]更复杂，而且要保证结果中的三元组不能重复。哈希表在这里不适用，因为这次不再是简单地查找`target - a`,而是`b + c = -a`，使用哈希表不仅需要多开一个空间，增加空间复杂度，还需要一个O(n^2)的时间复杂度来遍历。于是我们这里使用[[双指针]]来解决，尝试得到一个时间复杂度为O(n)，而且不需要额外空间的算法

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;
        int l = 0, r = nums.size() - 1;
        sort(nums.begin(), nums.end());
        for (int i = l + 1; i < r; i++){
            if (nums[i] + nums[l] + nums[r] == 0){
                ans.push_back({nums[i],nums[l],nums[r]});
            }
            if (nums[l] + nums[r] > 0){
                r--;
            }else{
                l++;
            }
        }
        return ans;
    }
};
```

这是我最开始想到的解法，确实实现了用双指针快速遍历，但是它是错误的，应为我没有**去重**。之后我又尝试了创建一个`set`用于去重，最后再转回`vector`，以及修改判断条件等，但是都失败了。结果发现连官方题解都使用了O(n^2)的‘解法，才发现我想得太简单了

这是修改之后的代码：

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> ans;
        int n = nums.size();
        sort(nums.begin(), nums.end());
        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i-1]) continue;
            int l = i + 1;
            int r = n - 1;
            int target = -nums[i];
            while (l < r) {
                int sum = nums[l] + nums[r];
                if (sum == target) {
                    ans.push_back({nums[i], nums[l], nums[r]});
                    while (l < r && nums[l] == nums[l+1]) l++;
                    while (l < r && nums[r] == nums[r-1]) r--;
                    l++;
                    r--;
                } else if (sum < target) {
                    l++;
                } else {
                    r--;
                }
            }
        }
        
        return ans;
    }
};
```

这里我们首先将数组排序，因为双指针适用于**有序的区间搜索**，然后进入第一层循环，循环变量是`b + c = -a`中的`-a`，对目标值去重后初始化左右指针和目标数，进入下一层循环。这一层循环中主要实现**去重**功能，就是当找到目标值时，直接通过移动指针将重复的值跳过
