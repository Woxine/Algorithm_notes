[10.无重复字符的最长字串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

这道题很适合用[[滑动窗口]]来做，而由于这个**窗口长度是动态的**，所以我们需要用[[双指针]]来维护窗口的端点。在更新数据的过程中，我们需要识别**重复的字符**，所以可以用[[哈希表]]存储当前字符来去重。这里哈希表中的键就是当前字符，值就是字符的索引，如果出现相同的字符，就将左指针的位置更新到这个重复字符第一次出现的位置之后。

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int n = s.length();
        unordered_map<char, int> charMap;
        int l = 0, ans = 0;
        for (int i = 0; i < n; i++) {
	        // 查找是否存在重复的字符，并且它在当前窗口内
            if (charMap.find(s[i]) != charMap.end() && charMap[s[i]] >= l) {
	            // 将左指针的位置更新到重复字符之后
                l = charMap[s[i]] + 1;
            }
            // 将右指针存进当前字符的索引
            charMap[s[i]] = i;
            // 更新最大长度
            ans = max(ans, i - l + 1);
        }
        return ans;
    }
};
```

## 总结

对于左右指针的维护是解这道题的关键，要搞清楚每次找到重复的字符，应当将左指针位置更新到**这个重复字符第一次出现的位置之后**。这里使用`unordered_map`而不是`unordered_set`是因为我们不是单纯地想要去重，我很还要维护左指针的下标
