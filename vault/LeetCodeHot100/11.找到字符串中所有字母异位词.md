[11.找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

因为给定异位词的长度是固定的，所以我首先想到的是用定长[[滑动窗口]]来做，关键在于如何判断窗口内字符串的字符与给定异位词的组成是否相同。我们在[[2.字母异位词分组]]中处理过异位词相关的问题，不过这里的情况不太一样：

```cpp
class Solution {
public:
    vector<int> findAnagrams(string s, string p) {
        vector<int> ans;
        // 用来记录字符出现次数
        array<int, 26> count_p{};
        array<int, 26> count_s{};
        for (char c : p) {
            count_p[c - 'a']++;
        }
        for (int i = 0; i < s.length(); i++) {
	        // 进入窗口
            count_s[s[i] - 'a']++;
            // 维护左指针
            int left = i - p.length() + 1;
            if (left < 0) {
                continue;
            }
            // 如果字符出现的次数相同，记录左指针位置
            if (count_p == count_s) {
                ans.push_back(left);
            }
            // 退出窗口
            count_s[s[left] - 'a']--;
        }
        return ans;
    }
};
```

## 新知识点

`array<int, 26> count_p{};`声明了一个固定大小的数组，它在保留了C风格数组功能的同时，自带边界检查，支持标准容器接口，还能和STL库协作
