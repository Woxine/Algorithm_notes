[1. 两数之和](https://leetcode.cn/problems/two-sum/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

我们需要在给定数组中找到和为**特定值**的两个数，很自然的，我想到通过两层循环遍历整个数组来找到符合要求的两个值：

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        int n = nums.size();
        for (int i = 0; i < n; i++){
            for (int j = i+1; j < n; j++){
                if (target - nums[i] == nums[j]){
                    return {i,j};
                }
            }
        }
        return {};
    }
};
```

但是我们不难发现，找到这两个数的时间复杂度在O(n^2)，而使用[[哈希表]]能够帮助我们将它简化

```cpp
class Solution {
public:
	vector<int> twoSum(vector<int>& nums, int target){
		unordered_map<int,int> hashtable;
		for (int i = 0; i < nums.size(); i++){
			int complete = target - nums[i];
			if (hashtable.find(complete) != hashtable.end()){
				return {i,hashtable[complete]};
			}
			hashtable[nums[i]] = i;
		}
		return {};
	}
}
```

从头开始遍历数组，每一轮循环都获得当前数的“补”，如果这个“补”已经存在于哈希表中，我们就能直接返回当前值和“补”的下标，否则，将当前值的下标存入哈希表中

*这里哈希表中的“键”是数组中具体的值，而它所对应的值才是数组的下标*

## 新知识点

- 查找表中是否存在对应的键/值：
```cpp

```

- 直接返回一个列表：
```cpp
return {i,j}
```
