[9.合并区间](https://leetcode.cn/problems/merge-intervals/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

这道题没什么弯弯绕绕的首先将这些区间按左端点大小排序，然后**有两个关键点**：
- 如果**当前区间的左端点**在**前一个区间的右端点**的**右侧**，直接将这个区间保留
- 如果不是，则保留前一个区间的左端点和**较大的右端点**

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort (intervals.begin(),intervals.end());
        vector<vector<int>> ans;
        for (int i = 0; i < intervals.size(); i++){
            int left = intervals[i][0], right = intervals[i][1];
            if (ans.empty() || ans.back()[1] < left){
                ans.push_back({left,right});
            }else{
                ans.back()[1] = max(ans.back()[1], right);
            }
        }
        return ans;
    }
};
```

*在我看来，所谓数据结构与算法，本质上就是在研究如何高效地组织，查找和操作数据。虽然这道题并没有涉及什么算法，但是“排序”这一操作就能体现上面这一点，因为它能够将数据更好地组织起来，便于对数据进行比较*
