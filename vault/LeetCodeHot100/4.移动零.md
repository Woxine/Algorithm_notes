[4.移动零](https://leetcode.cn/problems/move-zeroes/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

我们需要在给定的一个数组 `nums`中，将所有 `0` 移动到数组的末尾，同时保持非零元素的**相对顺序**

- 一种比较朴素的办法就是创建左指针`left = 0`，遍历数组，遇到非零数就将它挪到左指针的位置，然后`left++`，遍历一遍后就可以从左指针位置开始，将后面的位置都设成零：

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int left = 0;
        for (int i = 0; i < nums.size(); i++){
            if (nums[i] != 0){
                nums[left] = nums[i];
                left++;
            }
        }

        for (int i = left; i < nums.size(); i++){
            nums[i] = 0;
        } 
    }
};
```

这里**左指针**`left`就是**慢指针**，**循环变量**`i`就是**快指针**

- 然而实际上不需要这么麻烦，只要将非零元素和零**换位**就行了，反正都是就是将非零元素往前推，把零往后推，而左指针能够保证非零元素的**相对顺序**：

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int left = 0, n = nums.size();
        for (int i = 0; i < n; i++){
            if (nums[i]){
                swap(nums[left], nums[i]);
                left++;
            }
        }
    }
};
```

- 或者我们可以直接使用**迭代器**：

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        auto it = nums.begin();
        for(int i = 0; i < nums.size(); i++) {
            if(*it == 0){
                nums.erase(it);
                nums.push_back(0);
            }
            else 
                it++;
        } 
    }
};
```

## 新知识点

- [[双指针]]
- `swap(nums[left], nums[i])`直接交换两个值
- 迭代器的`erase()`,`push_back()`方法
