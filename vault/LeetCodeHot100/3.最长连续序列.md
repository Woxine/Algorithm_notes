[3.最长连续序列](https://leetcode.cn/problems/longest-consecutive-sequence/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

本题中，我们需要在给定一个未排序的整数数组 `nums` ，找出数字连续的最长序列，并且时间复杂度要在O(n)。当然可以直接将数组元素拷贝到一个`set`中，然后排序，最后遍历整个集合直接记录最长的连续序列，但是这个算法的时间复杂度来到了O(nlogn)，于是我们使用基于[[哈希表]]的[[并查集]]来解决：

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> set;
        for (int num : nums){
            set.insert(num);
        }
        int longest = 0;
        for (int num : set){
            if (!set.contains(num - 1)){
                int currentNum = num;
                int current = 1;
                while (set.count(currentNum + 1)){
                    currentNum++;
                    current++;
                }
                longest = max(longest,current);
            }
        }
        return longest;
    }
};
```

首先用`set`进行去重并初始化，然后遍历集合中的元素，判断是否存在比它小1的元素。如果有，那么它不是**根节点**，直接跳过；如果没有，说明它是某一个连续序列的**根节点**，记作`x`，初始化当前长度为1，然后寻找`x+1`,`x+2`,……，最后记录当前长度，将它与目前最长的序列比较，找到更长的，直到遍历整个集合。

这个算法的核心就在于利用**哈希表**的快速查找功能定位**根节点**，然后逐步找到序列最长的根节点。

## 新知识点

- `set` 提供了高效的**元素查找**、**插入**和**删除**操作。它是基于红黑树实现的，因此具有对数时间复杂度的查找、插入和删除性能。题目中用到的`unordered_set`是一种基于哈希表的容器，虽然不能保证元素的顺序，但是同样能够快速查找，插入和删除

- `set.contains()` 是 C++ 标准库中 `std::unordered_set` 和 `std::set` 容器的成员函数，用于检查集合中是否存在某个元素。
