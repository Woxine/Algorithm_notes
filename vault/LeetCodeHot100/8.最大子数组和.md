[8.最大子数组和](https://leetcode.cn/problems/maximum-subarray/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

### 动态规划

尽管题目要求我们找到最大的**连续**子数组，但是只关心结果，不关心具体从那开始，到哪结束。所以不用记录索引，只需要在遍历过程中不断查找最大的那个和就行了。

问题是，只要按顺序遍历数组就能确定**连续**，那么如何确定**最大**？

- [[动态规划]]：我们可以将`直到第i个数的最大子数组和的值`记作`dp[i]`，那么`dp[i]`可以写作`dp[i-1] + nums[i]`，**每一个子数组都能被拆分成更小的子数组**（倒是有一种递归的意思在里面）。如果当前的`nums[i]`加上`dp[i-1]`之后**反而变小了**，也就是说`dp[i-1]`是个负数，那么它就不可能是最大子数组和的一部分，**因为我们希望每一步得到的子数组尽可能增大**（这里就有点贪心算法的思想了）。于是我们可以直接将`dp[i-1]`舍掉，重新从`nums[i]`开始记

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n);
        dp[0] = nums[0];
        int maxsum = nums[0];
        for (int i = 1; i < n; i++) {
            dp[i] = max(nums[i], dp[i-1] + nums[i]);
            maxsum = max(dp[i], maxsum);
        }
        
        return maxsum;
    }
};
```

虽然通过了，但是我发现它慢得可怜

于是我参考了别人的答案，发现其实根本就不需要一个`vector`来储存，直接用两个变量就行了，下面是修改后的代码：

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int n = nums.size(), dp = 0;
        int maxsum = nums[0];
        for (int i = 0; i < n; i++) {
            dp = max(nums[i], dp + nums[i]);
            maxsum = max(dp, maxsum);
        }
        return maxsum;
    }
};
```

补充：一般都是用一个dp数组来写，但是这道题比较简单所以不用
