[6.盛水最多的容器](https://leetcode.cn/problems/container-with-most-water/description/?envType=study-plan-v2&envId=top-100-liked)
## 解题思路

想要解决这道题很简单，只要套两层循环遍历一遍然后找到最大值就行了，但是如此一来时间复杂度就来到了O(n^2)，所以我们这里用到了[[贪心算法]]这一思想，同时使用对向[[双指针]]来遍历，如此一来时间复杂度就到了O(n)

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int maxArea = 0, left = 0, right = height.size() - 1;
        while(left <= right){
            int edge = min(height[left], height[right]);
            int currentArea = edge * (right - left);
            maxArea = max(maxArea, currentArea);
            if (edge == height[left]){
                left++;
            }else{
                right--;
            }
        }
        return maxArea;
    }
};
```

两个指针分别从两端开始遍历，当前容量就是`较短的边的长度 * 两边间的距离`，循环中对两个指针的操作是关键：**每次将指向较短的边的指针向指向较长的边的指针靠近**

这里就体现了**贪心算法**的思想：我们希望每一步都得到最大的收益，而移动较长的边的指针并不会带来任何好处（因为容量由较短的边决定），相反，**无论我们如何移动较长的边的指针，容量都不会比当前更大了**，于是我们将指向较短的边的指针向指向较长的边的指针靠近，相当于再说：“已经不不需要它了，我们只考虑最优的”
