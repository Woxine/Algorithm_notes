[5.搜索插入位置](https://leetcode.cn/problems/search-insert-position/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

这道题相当简单，是最基本的[[二分算法]]几乎没有思维难度。但是，第一次写仍然容易出错，比如要注意**边界条件**，循环判断条件，避免进入死循环。同时这道题用到了类似于[[双指针]]一样的东西

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int left = 0, right = nums.size() - 1, mid = -1;
        while (left <= right){
        // 这里使用位运算以及不直接将两数相加是为了提高效率和避免数据溢出
        // (x + y)/2 = x + (y - x)/2 = x + y/2 - x/2 = x/2 + y/2
            mid = left + ((right - left) >> 1);
            if (nums[mid] < target){
                left = mid + 1;  // 这里不直接写left = mid是为了避免死循环
            }else{
                right = mid - 1;  // 同上
            }
        }
        return left;
    }
};
```
