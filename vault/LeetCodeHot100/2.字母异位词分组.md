[2.字母异位词分组](https://leetcode.cn/problems/group-anagrams/description/?envType=study-plan-v2&envId=top-100-liked)

## 解题思路

我们需要在一个字符串数组中找到**字母组成相同但是顺序不同**的词，并将它们分到一组。我们希望创建一个[[哈希表]]来查找这些词语，**关键就在于找到这些词的共同点，并将它作为键**

他们之间的唯一区别就是字母顺序不同，很自然的，我想到了排序，因为经过排序后的异位词肯定都是一样的。所以我们可以创建一个哈希表，遍历整个数组，将每个词进行排序，并将结果设为键，每当后续出现相同构成的词语，都会被纳入这个键所对应的`vector`中：

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> mp;
        for (string& str: strs){
            string key = str;
            sort(key.begin(), key.end());
            mp[key].push_back(str);
        }
        vector<vector<string>> ans;
        for (auto it = mp.begin(); it != mp.end(); ++it){
            ans.push_back(it -> second);
        }
        return ans;
    }
};
```

## 新知识点

- 迭代器遍历：
```cpp
for (auto it = mp.begin(); it != mp.end(); ++it){
            ans.push_back(it -> second);
        }
```

`auto`是自适应数据类型，这样就不用写一长串了；`it -> second`表示读取`it`中的第二个参数（也就是key-value中的value）
