[3760. 不同首字母的子字符串数目 - 力扣（LeetCode）](https://leetcode.cn/problems/maximum-substrings-with-distinct-start/description/)
## 题目拆解 / 题意分析

其实就是找字符串中有几个不同的字母吧

## 解题思路

## 代码实现

- 哈希表遍历：

```cpp
class Solution {
public:
    int maxDistinct(string s) {
        int ans = 1;
        int c[26] = {0};
        c[s[0] - 'a'] = 1;
        int len = s.size();
        for (int i = 1; i < len; i++) {
            if (c[s[i] - 'a'] == 0) {
                c[s[i] - 'a']++;
                ans++;
            }
        }
        return ans;
    }
};
```

- 哈希集合：

```cpp
class Solution {
public:
    int maxDistinct(string s) {
        unordered_set<char> cnt(s.begin(),s.end());
        return cnt.size();
    }
};
```

- [[位运算]]掩码：

```cpp
class Solution {
public:
    int maxDistinct(string s) {
        uint32_t mask = 0;
        for (char& c : s) {
            mask |= 1 << (c - 'a');
        }
        return popcount(mask);
    }
};
```

涉及到字母出现次数之类的情况，可以尝试位运算

## 知识补充

`popcount`用于计算一个整数的二进制表示中 **1 的个数**
