[3759. 统计合格元素的数目 - 力扣（LeetCode）](https://leetcode.cn/problems/count-elements-with-at-least-k-greater-values/description/)
## 题目拆解 / 题意分析

## 解题思路

- 排序 + 模拟：遍历数组，找到第一个比当前数大的数的下标，判断是否为合格元素，计数
- 排序 + 二分查找：

## 代码实现

- 模拟：

```cpp
class Solution {
public:
    int countElements(vector<int>& nums, int k) {
        ranges::sort(nums);
        int n = nums.size();
        int ans = 0;
        for (int i = 0; i < n; i++) {
            auto it = upper_bound(nums.begin(), nums.end(), nums[i]);
            int cnt = nums.end() - it;
            if (cnt >= k) {
                ans++;
            }
        }
        return ans;
    }
};
```

-  二分查找：

```cpp
class Solution {
public:
    int countElements(vector<int>& nums, int k) {
        ranges::sort(nums);
        int n = nums.size();
        if (!k) {
            return n;
        }
        return ranges::lower_bound(nums, nums[n - k]) - nums.begin();
    }
};
```

## 知识补充

再回顾一次这两个函数

`lower_bound(nums,nums[n-k])`返回`nums`中“第一个**大于或等于**”`nums[n-k]`的元素的位置
`upper_bound(nums,nums[n-k])`返回`nums`中“第一个**严格大于**”`nums[n-k]`的元素的位置

这两个函数都是基于[[二分算法]]实现的：

```cpp
int my_lower_bound(const vector<int> &nums, const int &val) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int mid = l + r >> 1;  // 等价于 (l + r) / 2
        if (nums[mid] >= val) 
            r = mid;  // 目标可能在mid或左边
        else 
            l = mid + 1;  // 目标一定在mid右边
    }
    return l;
}
```

```cpp
int my_upper_bound(const vector<int> &nums, const int &val) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int mid = l + r >> 1;
        if (nums[mid] > val) 
            r = mid;  // 目标可能在mid或左边
        else 
            l = mid + 1;  // 目标一定在mid右边
    }
    return l;
}
```
