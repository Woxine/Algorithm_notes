[3761. 镜像对之间最小绝对距离 - 力扣（LeetCode）](https://leetcode.cn/problems/minimum-absolute-distance-between-mirror-pairs/description/)
## 题目拆解 / 题意分析

两个关键点：
- 下标要满足 i < j，不能反过来；
- 反转后的数字会忽略前导零，所以 120 反转后会变成 21，而 21 反转后不会变成 120（而是12）

## 解题思路

[[枚举右，维护左]]：倒序遍历（所以其实是枚举左，维护右），枚举 i，同时用[[哈希表]]维护 j 的最小下标；如果左边出现了 `reverse(nums[j])`，更新答案

## 代码实现

```cpp
class Solution {
public:
    int reverseNum(int num) {
        int reversed = 0;
        while (num > 0) {
            reversed = reversed * 10 + num % 10;
            num /= 10;
        }
        return reversed;
    }
    int minMirrorPairDistance(vector<int>& nums) {
        vector<int> temp = nums;
        int n = nums.size();
        int ans = INT_MAX;
        unordered_map<int, int> lastPos;
        for (int i = n - 1; i >= 0; i--) {
            int r = reverseNum(temp[i]);
            if (lastPos.count(r)) {
                ans = min(ans, lastPos[r] - i);
            }
            lastPos[temp[i]] = i;
        }
        return ans == INT_MAX ? -1 : ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(nlogU)**

其中 n 是 nums 的长度，U=max(nums)

### 空间复杂度：**O(n)**

## 总结 / 错误反思

本来是嵌套循环暴力求解的，超时了
