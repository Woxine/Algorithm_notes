[3747. 统计移除零后不同整数的数目 - 力扣（LeetCode）](https://leetcode.cn/problems/count-distinct-integers-after-removing-zeros/description/)
## 题目拆解 / 题意分析

数据量太大，直接遍历肯定是不行的，要想办法在数学性质上做文章

首先我们知道，移除零后，数就会“降级”，四位数变成三位数；三位数变成两位数。我们从一位数开始思考，1-9肯定是不会重复的，但是一旦”升级“到两位数，比如 10，去掉 0 之后会降级成 1，重复；同样的道理，102 去掉 0 之后会降级成 12，重复。到这里我们就发现了，每一个带 0 的数一定会降级成已经计算过的数，于是原问题就变成了：

*对于从 1 到 n 的每个整数 x，一共有多少个数不带 0 ？*

设 n 的位数为 len，那么位数比 n 少的数中，不带零的个数是固定的，是一个首项为 9，公比为 9 的等比数列求和（n >= 9），所以剩下的问题就是：

*对于 $10^{len-1}$ 到 n 的每个整数 x，一共有多少个数不带 0 ？*

## 解题思路

[[动态规划]]：考虑位数恰好等于 len 的数，我们从最高位开始遍历，每一位都有两种情况：

- 选择与 n 当前位相同的数，后续选择受限
- 选择比 n 当前位小的数，那后续的数可以从1-9任选

如果是第二种情况，计算方式又和位数比 n 小的数相同，于是我们已经找到子问题了

边界条件就是遍历到最后一位

要注意如果 n 当前位为 0，那就没有选择空间了
## 代码实现

```cpp
class Solution {
public:
    long long countDistinct(long long n) {
        string s = to_string(n);
        int len = s.size();
        // base 表示位数少于n的位数的整数数量
        long long base = 0;
        long long pow9 = pow(9, len);
        base = (pow9 - 9) / 8; // 等比数列求和
        long long remain = 0;
        // 计算长度恰好等于 len 的不含 0 的整数个数
        // 分为两种情况：当前位大小与 n 相同；当前位大小小于 n
        // 前者后续的数字的选择有限，而后者的后续可以在1-9任选
        for (int i = 0; i < len; i++) {
            char c = s[i];
            // 当前位为零则无效
            if (c == '0') {
                break;
            }
            int cur = c - '1';  // 比当前数小1的数的个数
            // 特判最后一位，因为没有后续位数要处理了，所以可以算上自己
            if (i == len - 1) {
                cur++;
            }
            pow9 /= 9;  // 每少一位，9的幂减一
            remain += cur * pow9;  // 加法原理和乘法原理
        }
        return base + remain;
    }
};
```

### 时间复杂度：**O(logn)**

开销与 n 的长度有关

### 空间复杂度：**O(logn)**
