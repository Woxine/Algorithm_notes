[3752. 字典序最小和为目标值且绝对值是排列的数组 - 力扣（LeetCode）](https://leetcode.cn/problems/lexicographically-smallest-negated-permutation-that-sums-to-target/description/)
## 题目拆解 / 题意分析

要想字典序最小，那么数组中最小的负数应当尽量小；

一个由 1 到 n 的排序，其和为 n(n+1)/2 ，一定是个偶数；所以如果目标值大于最大和，或者它们之间的差值为奇数，即不能通过调整 n(n+1)/2 来得到，就不合法

## 解题思路

[[贪心算法]]：先得到一个大小为 n，从 1 开始升序填充的数组 ans；然后从最大的数（末尾的数）开始遍历，贪心地将它改成负的，如果修改后能达到目标，则修改并退出循环，返回 ans；如果修改后剩下的和仍大于目标，更新剩余和并修改数组，继续遍历；如果修改会使总和小于目标，说明改大了，跳过这一步修改；最后给 ans 排个序，让它符合字典序

## 代码实现

```cpp
class Solution {
public:
    vector<int> lexSmallestNegatedPerm(int n, long long target) {
        long long abs_sum = 1LL * n * (n + 1) / 2;
        if (abs_sum < abs(target) || (abs_sum - target) % 2 != 0) {
            return {};
        }
        vector<int> ans(n);
        iota(ans.begin(), ans.end(), 1);
        for (int i = n - 1; i >= 0; i--) {
            long long remain = abs_sum - 2 * ans[i];
            if (remain == target) {
                ans[i] = -ans[i];
                break;
            } else if (remain > target) {
                abs_sum -= 2 * ans[i];
                ans[i] = -ans[i];
            } else {
                continue;
            }
        }
        ranges::sort(ans);
        return ans;
    }
};
```

题解优化：

```cpp
class Solution {
public:
    vector<int> lexSmallestNegatedPerm(int n, long long target) {
        long long abs_sum = 1LL * n * (n + 1) / 2;
        if (abs_sum < abs(target) || (abs_sum - target) % 2) {
            return {};
        }
        vector<int> ans(n);
        long long neg = (abs_sum - target) / 2;  // 取符号的元素（的绝对值）之和
        int l = 0, r = n - 1;
        // 直接用循环参数填充 ans，省去iota的部分
        // 同时省去修改 ans 的操作，直接填充
        // 从 1,2,...,n 中选一些数，使得它们的和为 neg
        for (int i = n; i > 0; i--) {
            if (neg >= i) {
                neg -= i;
                ans[l++] = -i;
            } else {
                ans[r--] = i;
            }
        }
        return ans;
    }
};
```
