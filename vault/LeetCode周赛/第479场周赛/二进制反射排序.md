## 代码实现

```cpp
class Solution {
public:
    int rev(int n) {
        int r = 0;
        while (n) {
            r = (r << 1) | (n & 1);
            n >>= 1;
        }
        return r;
    }
    vector<int> sortByReflection(vector<int>& nums) {
        sort(nums.begin(), nums.end(), [&](int a, int b) {
            return make_pair(rev(a), a) < make_pair(rev(b), b);
        });
        return nums;
    }
};
```

## 知识补充

[[位运算]]大数反转：

```cpp
int rev(int n) {
    int r = 0;
    while (n) {
	    // r 左移一位，取 n 的最低位
        r = (r << 1) | (n & 1);
        // n 右移一位
        n >>= 1;
    }
    return r;
}
```

自定义 sort 函数：

```cpp
sort(nums.begin(), nums.end(), [&](int a, int b) {
    return make_pair(rev(a), a) < make_pair(rev(b), b);
});
```

这是一个内置lambda函数的sort函数，a，b表示遵循以下排序规则的两个数；make_pair会创建一个pair，当你比较两个pair时，会先比较前面那个元素，如果相同才会比较后面那个。
