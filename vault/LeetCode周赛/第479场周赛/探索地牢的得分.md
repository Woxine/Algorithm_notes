[3771. 探索地牢的得分 - 力扣（LeetCode）](https://leetcode.cn/problems/total-score-of-dungeon-runs/description/)
## 题目拆解 / 题意分析

倒过来想：对于每个房间 i ，有多少个起点 j 能安全到达 i
起点越远，收到的伤害越多，越难达到终点，具有单调性，能够用[[二分算法]]找

## 解题思路

## 代码实现

```cpp
class Solution {
public:
    long long totalScore(int hp, vector<int>& damage,
                         vector<int>& requirement) {
        int n = damage.size();
        vector<int> prefix(n + 1);
        long long ans = 0;
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + damage[i];
            int limit = prefix[i + 1] + requirement[i] - hp;
            int j = lower_bound(
		            prefix.begin(), 
		            prefix.begin() + i + 1, 
		            limit) - prefix.begin();
            ans += i - j + 1;
        }
        return ans;
    }
};
```
