[3755. 最大平衡异或子数组的长度 - 力扣（LeetCode）](https://leetcode.cn/problems/find-maximum-balanced-xor-subarray-length/)
## 题目拆解 / 题意分析

这道题我们要找“某个符合特殊条件的连续子数组”，一下就能想到[[前缀和]]+[[哈希表]]，不过这次要复杂一些：前缀异或和+带两个参数的哈希表。这道题对于子数组有两个要求，所以哈希表中的键需要存储两个参数的信息，一个是异或和为 0，一个是奇偶差为 0

## 解题思路

前缀异或和 + 哈希表：子数组 `[l,r) 的异或和即 s[r] ⊕ s[l]`，`s[r] ⊕ s[l] = 0 意味着 s[r] = s[l]`；同时，奇偶差为 0 同样可以用前缀和来计算

## 代码实现

```cpp
class Solution {
public:
    int maxBalancedSubarray(vector<int>& nums) {
        int ans = 0;
        int n = nums.size();
        // 记录不同异或和第一次出现时的下标
        unordered_map<long long, int> firstIndex;
        int prefixXOR = 0;
        int diff = 0; // 偶减奇

        firstIndex[0] = -1;
        for (int i = 0; i < n; i++) {
            prefixXOR ^= nums[i];
            diff += nums[i] % 2 ? -1 : 1;
			// 将两个指标合成一个键，同时保证diff非负
			// 前32位储存异或和，后32位储存 diff
            long long k = 1LL * prefixXOR << 32 | (diff & 0xFFFFFFFFLL);
            if (firstIndex.find(k) != firstIndex.end()) {
                int index = firstIndex[k];
                ans = max(ans, i - index);
            } else {
                firstIndex[k] = i;
            }
        }
        return ans;
    }
};
```

## 知识补充

回顾我们对前缀和的总结：**它本质上是对容器内某一批量操作的存档**，借助预处理来达到空间换时间的效果。对于加法是这样，对于减法（差分），乘法，等等都是有效的，这题就是前缀和的一个变种：前缀异或和

异或操作有两个关键的性质：

- **结合律**和**交换律**：我们可以重新组合项
- **自逆性**：`x ⊕ x = 0`，所以相同的项会相互抵消
