[移山所需的最少秒数](https://leetcode.cn/problems/minimum-number-of-seconds-to-make-mountain-height-zero/)
## 解题思路

- 花费的时间越多，降低的高度越多，**具有单调性**，可以用[[二分算法]]。我们需要更新时间，然后计算工人们在这个时间内能移除多少高度，如果这个高度小于山的高度，说明时间长了，要缩短；否则要增加时间。于是我们需要计算一个工人在某一时间内能移除多少高度，然后累加这个高度，判断是否达标

```cpp
class Solution {
public:
    long long minNumberOfSeconds(int mountainHeight, vector<int>& workerTimes) {
	    // 这是一种匿名函数的写法，跟灵神学的
        auto check = [&](long long m) {
            int h_left = mountainHeight;
            // 这个表达式是一个一元二次方程的正根，因为计算时间的方式是个等差数列
            // 将工人能移除的高度设为未知数，剩下的变量设成参数求解
            for (int t : workerTimes) {
                h_left -= ((int)sqrt(m / t * 8 + 1) - 1) / 2;
                if (h_left <= 0) {
                    return true;
                }
            }
            return false;
        };
        int max_t = ranges::max(workerTimes);
        // 关于二分区间的上下界，因为这里用的是开区间写法
        // 所以左边要保证一定不满足，右边要保证一定满足
        int h = (mountainHeight - 1) / workerTimes.size() + 1;
        long long left = 0, right = (long long)max_t * h * (h + 1) / 2;
        while (left + 1 < right) {
            long long mid = left + (right - left) / 2;
            (check(mid) ? right : left) = mid;
        }
        return right;
    }
};
```

- 小根[[堆]]模拟：

```cpp
class Solution {
public:
    long long minNumberOfSeconds(int mountainHeight, vector<int>& workerTimes) {
        // 三元组记录参数
        priority_queue<tuple<long long, long long, int>, vector<tuple<long long, long long, int>>, greater<>> pq;
        for (int t : workerTimes) {
            pq.emplace(t, t, t);
        }
        long long ans = 0;
        while (mountainHeight--) {
            // 工作后总用时，当前工作（山高度降低 1）用时，workerTimes[i]
            auto [nxt, delta, base] = pq.top(); 
            pq.pop();
            ans = nxt; // 最后一个出堆的 nxt 即为答案
            pq.emplace(nxt + delta + base, delta + base, base);
        }
        return ans;
    }
};
```

## 新知识点

什么是 lambda 表达式？

Lambda 表达式是 C++11 及以上标准引入的一种匿名函数（没有函数名的函数），可以在需要函数的地方直接定义和使用，主要用于简化代码、编写简短的回调函数或作为算法的参数。

它的基本语法结构是：

```cpp
[capture-list](parameters) -> return-type {
    // 函数体
}
```

各部分含义：

- **捕获列表（capture-list）**：用于捕获外部变量（在 lambda 表达式所在作用域中的变量），使其能在函数体内使用。常见形式有：
    - `[]`：不捕获任何外部变量
    - `[=]`：按值捕获所有外部变量（函数体内使用的是副本）
    - `[&]`：按引用捕获所有外部变量（函数体内使用的是原变量的引用）
    - `[x, &y]`：按值捕获 x，按引用捕获 y
- **参数列表（parameters）**：与普通函数的参数列表类似，用于接收输入参数
- **返回类型（return-type）**：通常可以省略，编译器会根据 return 语句自动推导
- **函数体**：包含具体的逻辑实现

本题中，这就是一个Lambda 表达式：

```cpp
auto check = [&](long long m) {
    // 函数体
};
```

- `[&]` 表示按引用捕获所有外部变量（如 `mountainHeight`、`workerTimes`）
- `(long long m)` 是参数列表
- 返回类型被省略（编译器会推导出是 `bool` 类型）
- 函数体实现了 “判断 m 秒内能否挖平山体” 的逻辑

通过 `auto check = ...` 将这个匿名函数赋值给变量 `check`，之后就可以像使用普通函数一样调用 `check(mid)` 了
## 总结

二分法的关键就在于check函数的实现，这里有几个关键点：

- 区间上下界的确定：左界表示比最小的情况还小（无法满足）；右界表示比最大的情况还大（一定能满足）
- 累加量的计算
