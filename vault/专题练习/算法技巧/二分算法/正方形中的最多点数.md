[正方形中的最多点数](https://leetcode.cn/problems/maximum-points-inside-the-square/)
## 解题思路

正方形的半边长越小，包含的点越少，越容易合法，**具有单调性**，可以用[[二分算法]]求最大值
我们先**二分正方形的边长**，然后求这个范围内有多少点，**间接地**得到答案

```cpp
class Solution {
public:
    int maxPointsInsideSquare(vector<vector<int>>& points, string s) {
	    // 用数组存储标签的情况
        int count[26]{}, ans = 0;
        auto check = [&](int m) {
            for (int i = 0; i < points.size(); i++) {
	            // 遇到重复的点就标记，变化的 m 使得不需要重复创建数组
                if (max(abs(points[i][0]), abs(points[i][1]))<= m) {
                    if (count[s[i] - 'a'] != m) {
                        count[s[i] - 'a'] = m;
                    } else {
                        return false;
                    }
                }
            }
            return true;
        };
        int left = 0, right = 1000000001;
        while (left + 1 < right) {
            int mid = (left + right) / 2;
            (check(mid) ? left : right) = mid;
        }
        // 计算一共有多少个点
        for (auto p : points) {
            if (max(abs(p[0]), abs(p[1])) <= left) {
                ans++;
            }
        }
        return ans;
    }
};
```

然后看了题解，有一种更高效的解法，只要正方形的半边长小于每一种标点到原点的次最小（就是除了最近的那个之外最近的那个）距离，就一定合法，维护这个值，得到半边长，最后求解

整个过程中有两个值要更新，一个是最小距离，一个是次小距离

```cpp
class Solution {
public:
    int maxPointsInsideSquare(vector<vector<int>>& points, string s) {
	    // min_d 存储了这一种标签的点到原点的最小距离
	    // min2 则存储了min_d 中的最小值
        int min_d[26], min2 = INT_MAX;
        ranges::fill(min_d, INT_MAX);
        for (int i = 0; i < points.size(); i++) {
	        // 当前点到原点的距离
            int d = max(abs(points[i][0]), abs(points[i][1]));
            char c = s[i] - 'a';
            // 如果这个距离是这种标签中最小的
            if (d < min_d[c]) {
	            // min_d 就不再是最小距离而是次小距离
                min2 = min(min_d[c], min2);
                // 更新最小距离
                min_d[c] = d;
            } else {
		        // d 也有可能是次小距离
                min2 = min(min2, d);
            }
        }
        int ans = 0;
        for (auto d : min_d) {
	        // 统计范围内所有点
            ans += d < min2;
        }
        return ans;
    }
};
```

## 总结

分析是解题的关键，将原问题转化为"正方形内不能包含相同标签的两个点"的条件。通过观察发现，正方形边界的临界点由每个标签的次小距离决定。当正方形半边长 `L` 小于某个标签的次小距离时，该标签最多只有一个点被包含（即最小距离的点）

方法一也有优化空间，用哈希表而不是数组存储可以直接通过`map.size()`求出有多少个点
