[每个小孩最多能分到多少糖果](https://leetcode.cn/problems/maximum-candies-allocated-to-k-children/)
## 解题思路

对每个孩子能分到糖果的数量进行二分，分到的糖果越少，能分出的子堆越多，越能分出来，**具有单调性**。

```cpp
class Solution {
public:
    int maximumCandies(vector<int>& candies, long long k) {
        auto check = [&](int mid) {
            long long pile = 0;
            for (int num : candies) {
                pile += (num / mid);
            }
            return pile >= k;
        };
        int left = 0, right = ranges::max(candies) + 1;
        while (left + 1 < right) {
            int mid = left + (right - left) / 2;
            (check(mid) ? left : right) = mid;
        }
        return left;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(nlogm)**

其中 n 是 candies 的长度，m 是右端点初始值，每次 check 都要遍历一次数组，时间复杂度是 O(n)，然后通过二分法找答案的开销是 O(logm)，一共是**O(nlogm)**

### 空间复杂度：**O(1)**

求**最大值**的题都是**越小越合法**，在一堆小的里找最大的；
