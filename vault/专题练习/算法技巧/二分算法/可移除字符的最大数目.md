[可移除字符的最大数目](https://leetcode.cn/problems/maximum-number-of-removable-characters/)
## 解题思路

移除的字符越少，越容易到达要求，**具有单调性**，可以用[[二分算法]]。只要对 k 进行二分，然后按照题意进行判断即可。题目中所说的“**移除**”也可以视作“**标记**”，我在尝试过程中分别用了**布尔数组**和**创建副本**两种方式进行标记，它们在复杂度方面略有不同

- 布尔数组

```cpp
class Solution {
public:
    int maximumRemovals(string s, string p, vector<int>& removable) {
        auto check = [&](int m) {
            vector<bool> removed(s.size(), false);
            for (int j = 0; j < m; j++) {
                removed[removable[j]] = true;
            }
            int count = 0;
            for (int i = 0; i < s.size(); i++) {
                if (!removed[i] && p[count] == s[i]) {
                    count++;
                }
            }
            return count == p.size() ? true : false;
        };
        int left = 0, right = removable.size() + 1;
        while (left + 1 < right) {
            int mid = left + (right - left) / 2;
            (check(mid) ? left : right) = mid;
        }
        return left;
    }
};
```

- 副本

```cpp
class Solution {
public:
    int maximumRemovals(string s, string p, vector<int>& removable) {
        int n = s.size();
        auto check = [&](int m) {
            string cs = s;
            int count = 0;
            for (int j = 0; j < m; j++) {
                cs[removable[j]] = '*';
            }
            for (int i = 0; i < n; i++) {
                if (p[count] == cs[i]) {
                    count++;
                }
                if (count == p.size()) {
                    return true;
                }
            }
            return false;
        };
        int left = 0, right = removable.size()+1;
        while (left + 1 < right) {
            int mid = left + (right - left) / 2;
            (check(mid) ? left : right) = mid;
        }
        return left;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(nlogk)**

其中`n` 是字符串 `s` 的长度，`k` 是数组 `removable` 的长度（即最多可移除的元素数量）
两者的总时间复杂度均为 **二分次数 × 单次 `check` 开销** = `O(log k) × O(n)` = `O(n·log k)`
但是第二种方法避免了`vector<bool>`的额外开销，所以要稍微快一点

### 空间复杂度：**O(n)**

虽然它们的空间复杂度都是`O(n)`，但是细节上有所不同：
- 第一份代码的临时空间是字符串副本（`O(n)` 字节，每个字符占 1 字节）。
- 第二份代码的临时空间是布尔数组（`O(n)` 比特，约 `n/8` 字节）。
因此，**第二份代码的实际内存占用更小**（尤其是当 `n` 很大时，差距更明显）
