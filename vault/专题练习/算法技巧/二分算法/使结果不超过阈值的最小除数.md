[使结果不超过阈值的最小除数](https://leetcode.cn/problems/find-the-smallest-divisor-given-a-threshold/)
## 解题思路

我们想要找到一个满足条件的”**最小**“除数，自然是从小到大枚举，这样的枚举具有”**单调性**“，所以可以用二分法来找。随着除数逐渐增大，对除法结果求和的结果**单调递减**，知道找到第一个（也就是最小的）使得除法结果之和小于等于目标的除数

```cpp
class Solution {
public:
    int smallestDivisor(vector<int>& nums, int threshold) {
	    // 这里采用开区间的写法，所以左指针在数组外面
	    // 因为除数不可能超过数组中最大的数，所以右指针就是数组中最大的数
        int left = 0, right = ranges::max(nums);
        // 当 left + 1 == right 时跳出循环
        while (left + 1 < right) {
	        // 防止数据溢出
            int mid = left + (right - left) / 2;
            int sum = 0;
            for (int n : nums) {
		        // 这里 mid 就是要找的除数
		        // 这是向上取整的式子
		        // 也可以写成 (a - 1) / b + 1
                sum += (n + mid - 1) / mid;
                if (sum > threshold){
                    break;
                }
            }
            // 说明除数不够小，于是右移左指针，增大除数
            // 此时保证left及其左边的数都小于目标除数
            // right及其右边的数都大于等于目标除数
            if (sum > threshold) {
                left = mid;
            } else {
                right = mid;
            }
        }
        return right;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(nlogU)**

其中 n 是 nums 的长度，U=max(nums)，二分 O(logU) 次，每次 O(n) 遍历 nums

### 空间复杂度：**O(1)**

## 新知识点

关于向上取整的式子，就是对`(a - 1) /b`向下取整再加 1，因为：

- 如果`a mod b == 0`，那么`(a - 1) / b`向下取整就能得到比`a / b`小的值，此时再加一，就能达到向上取整的效果
- 如果`a mod b != 0`，无论怎么样（即使`(a - 1) mod b == 0`）直接向下取整就能得到比`a / b`小的值，直接加一就能达到向上取整的效果

## 总结

二分法最关键的就是两个指针的位置及其含义，对于开区间来讲，**left及其左边的数都小于目标除数**；**right及其右边的数都大于等于目标除数**。当循环结束时，**区间中将没有元素**，此时right的位置就指向了第一个使结果小于等于阈值的除数

关键在于：**区间端点的含义，以及区间外到底有什么**，毕竟循环结束时，区间是空的，内部的元素并不能帮我们更新左右指针的位置，我们关心的是，**更新指针后被排除在区间外的元素是不是真正不符合要求的**
