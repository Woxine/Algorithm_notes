[在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)
## 解题思路

暴力方法自然是遍历整个数组，找到与目标值相等的数，这样时间复杂度为**O(n)**。但是我们要利用好“**数组是有序的**”这一条件，利用[[二分算法]]就能大大减少步骤，将时间复杂度降到**O(logn)**

二分查找本质上还是用对向双指针来实现的，所以我们先初始化左右指针，大体上讲有三种方法构造这个区间，但都大差不差：

- 半开半闭
- 全开
- 全闭

这里选全开，以下是代码：

```cpp
class Solution {
    int binary_search(vector<int>& nums, int target) {
	    // 初始化，因为是全开，所以一开始指针在数组外面
        int left = -1, right = nums.size();
        while (left + 1 < right) {
	        // 这里不直接写 mid = (right + left) / 2; 是为了防止数据溢出
            int mid = left + (right - left) / 2;
            // 最后right会停在第一次等于 target 的位置
            if (nums[mid] >= target) {
                right = mid;
            } else {
                left = mid;
            }
        }
        return right;
    }

public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int start = binary_search(nums, target);
        if (start == nums.size() || nums[start] != target) {
            return {-1, -1};
        }
        // 想要得到等于 target 的最后一个数
        // 只要获取第一给比 target 大1的数的前一个位置就行了
        int end = binary_search(nums, target + 1) - 1;
        return {start, end};
    }
};
```

## 复杂度分析

### 时间复杂度：**O(logn)**

其中 n 为 nums 的长度

### 空间复杂度：**O(1)**

仅用到若干额外变量
