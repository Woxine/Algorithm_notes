[求出最多标记下标](https://leetcode.cn/problems/find-the-maximum-number-of-marked-indices/)
## 解题思路

这道题有两种解法，[[双指针]]和[[二分算法]]，但是重点都在于对题意的分析上
题目要求- 选择两个 **互不相同且未标记** 的下标 `i` 和 `j` ，满足 `2 * nums[i] <= nums[j]` ，标记下标 `i` 和 `j` 。也就是说要**找到 k 对满足条件的数**，k 越小，越容易满足，**具有单调性**

现在来分析这 k 对数，如果这 k 对数真的存在，那么会是哪 k 对呢？答案是由排好序的前 k 个数与后 k 个数组成的，k 的值不会超过数组的一半

- 排序+二分

```cpp
class Solution {
public:
    int maxNumOfMarkedIndices(vector<int>& nums) {
	    // 排序
        ranges::sort(nums);
        int n = nums.size();
        auto check = [&](int m) {
            for (int i = 0; i < m; i++) {
            // 考察前 k 个数与后 k 个数的第 i 个
                if (nums[i] * 2 > nums[n - m + i]) {
                    return false;
                }
            }
            return true;
        };
        // k 的值不会超过数组的一半
        int left = 0, right = n / 2 + 1;
        while (left + 1 < right) {
            int mid = left + (right - left) / 2;
            (check(mid) ? left : right) = mid;
        }
        return left * 2;
    }
};
```

- 排序+双指针

```cpp
class Solution {
public:
    int maxNumOfMarkedIndices(vector<int>& nums) {
        ranges::sort(nums);
        int n = nums.size(), i = 0;
        for (int j = (n + 1) / 2; j < n; j++) {
            if (nums[i] * 2 <= nums[j]) {
                i++;
            }
        }
        return i * 2;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(nlogn)**

其中 n 为 nums 的长度

对于第一种方法：
- 排序操作（`ranges::sort`）的时间复杂度为 O (n log n)
- 二分查找部分：二分的范围是 [0, n/2]，最多执行 O (log n) 次
- 每次二分检查（`check` 函数）需要 O (m) 时间，其中 m 最大为 n/2，即 O (n)
- 因此二分部分总时间为 O (n log n)
- 整体由排序操作主导，总时间复杂度为 O (n log n)

第二种方法：
- 排序操作同样是 O (n log n)
- 双指针遍历部分：两个指针最多各移动 n 次，总遍历时间为 O (n)
- 整体由排序操作主导，总时间复杂度为 O (n log n)
### 空间复杂度：**O(1)**

## 新知识点

sort 函数虽然方便，但是会带来 O(nlogn) 的时间复杂度，必要条件下需要自己写排序
