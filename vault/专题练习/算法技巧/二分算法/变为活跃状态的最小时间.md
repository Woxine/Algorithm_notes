[变为活跃状态的最小时间](https://leetcode.cn/problems/minimum-time-to-activate-string/)
## 解题思路

这是最近的一道周赛题，当时我没学二分，也不会枚举，卡了好久都没做出来，现在来补一下
时间越长，变成星号的字符越多，越容易满足条件，**具有单调性**，可以用[[二分算法]]。然后就是要对有效字符串进行枚举，从左到右遍历 s，同时维护最近遍历到的星号的下标 last，一共有 last + 1 个

```cpp
class Solution {
public:
    int minTime(string s, vector<int>& order, int k) {
        int n = s.size();
        // 如果全变成 * 都不行，返回 -1
        if ((long long)n * (n + 1) / 2 < k)
            return -1;
		// 开一个 vector 记录 * 位置
        vector<int> star(n);

        auto check = [&](int m) {
	        // 题目虽说“标记为 * ”，但是实际上我们不需要真的执行这个操作
	        // 只需要把对应字符“标记下来就行”
            for (int i = 0; i < m; i++) {
                star[order[i]] = m;
            }
            int last = -1, count = 0;
            for (int j = 0; j < n; j++) {
                if (star[j] == m) {
                    last = j;
                }
                count += last + 1;
                // 如果有效字符串足够，缩短时间；否则延长
                if (count >= k) {
                    return true;
                }
            }
            return false;
        };
        int left = -1, right = n - 1;
        while (left + 1 < right) {
            int mid = left + (right - left) / 2;
            (check(mid + 1) ? right : left) = mid;
        }
        return right;
    }
};
```

其中 n 是 s 的长度

### 空间复杂度：**O(n)**
