[供暖器](https://leetcode.cn/problems/heaters/)
## 解题思路

这是一道运用[[二分算法]]库函数的例题，核心思路是：让每个房屋去找**最近的**供暖器，然后找到这个最近的距离的**最大值**，那么这个**最大值**就是答案。但其实我们找的是**最小加热半径**，求出来的最大值的“**最大**”是为了保证能将房屋**全部覆盖到**

```cpp
class Solution {
public:
    int findRadius(vector<int>& houses, vector<int>& heaters) {
        int ans = 0;
        // 先排序（说实话我不知道题目设计这个的意义是什么）
        sort(heaters.begin(), heaters.end());
        for (int house : houses) {
	        // upper_bound函数会返回第一个大于目标值的元素的迭代器
	        // upper_bound减去begin()得到下标
	        // 于是我们就得到了房屋右边最近的供暖器
            int right = upper_bound(heaters.begin(), heaters.end(), house) -
                    heaters.begin();
            // 得到房屋左边最近的供暖器
            // 这个left会小于或者等于house的位置
            int left = right - 1;
            int rightDis = 
	            right >= heaters.size() ? INT_MAX : heaters[right] - house;
            int leftDis = left < 0 ? INT_MAX : house - heaters[left];
            // 找到最小半径
            int cur = min(leftDis, rightDis);
	        // 计算最小半径中最大的那个
            ans = max(ans, cur);
        }
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O((n+m)logn)**

其中 m 是数组 houses 的长度，n 是数组 heaters 的长度
排序+二分 分别需要O(klogk)的复杂度，加起来就是O((n+m)logn)
### 空间复杂度：**O(logn)**

主要是排序带来的开销
