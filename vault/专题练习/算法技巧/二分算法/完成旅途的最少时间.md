[完成旅途的最少时间](https://leetcode.cn/problems/minimum-time-to-complete-trips/)
## 解题思路

随着时间的增长，完成的旅途会**单调递增**，于是我们可以用[[二分算法]]来找答案，这里用的是二分答案，其实跟上一题非常像

```cpp
class Solution {
public:
    long long minimumTime(vector<int>& time, int totalTrips) {
        int min_t = ranges::min(time);
        // 左指针是最快的车跑一趟的时间减一，一定在区间外
        // 右指针是最快的车跑完全程的时间，肯定满足要求
        long long left = min_t - 1, right = 1LL*min_t*totalTrips;
        while (left + 1 < right) {
            long long mid = left + (right - left) / 2;
            long long sum = 0;
            for (int t : time) {
                sum += mid / t;
            }
            if (sum < totalTrips) {
                left = mid;
            } else {
                right = mid;
            }
        }
        return right;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(nlogU)**

其中 n 为 time 的长度，U 为二分上下界之差。在本题数据范围下，U≤$10^{14}$。

### 空间复杂度：**O(1)**
