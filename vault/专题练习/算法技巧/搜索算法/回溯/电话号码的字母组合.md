[电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)
## 题目拆解 / 题意分析

根据题意，最终会生成一系列长度与 digit 相等的字符串，构成这些字符串的过程能够看作一棵树，对于每个按键对应的三/四个字符，都有“选”或“不选”两条路径

## 解题思路

[[递归]] + dfs + [[回溯]]：递归边界即路径长度与 digit 相等，返回当前路径；每次到 digit 中新的一位，遍历对应的 3/4 个字符，直到这一层遍历完，回溯到上一层

## 代码实现

```cpp
class Solution {
    static constexpr string MAP[10] = {"",    "",    "abc",  "def", "ghi",
                                       "jkl", "mno", "pqrs", "tuv", "wxyz"};
public:
    vector<string> letterCombinations(string digits) {
        vector<string> ans;
        int n = digits.size();
        if (!n) {
            return {};
        }
        string path(n, 0);
        auto dfs = [&](this auto&& dfs, int i) -> void {
	        // 边界条件
            if (i == n) {
                ans.emplace_back(path);
                return;
            }
            for (char c : MAP[digits[i] - '0']) {
                path[i] = c; // 直接通过赋值覆盖掉原值，省去显式回溯操作
                dfs(i + 1); // 递归遍历下一个字符
            }
        };
        dfs(0);
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O($4^n$)**

最坏情况每个数字对应4个字母，其中 n 为 digit 长度

### 空间复杂度：**O(n)**

开销主要来自递归栈深度和path长度
