## 题目拆解 / 题意分析

一个包含 n 个元素的集合的子集数量为 $2^n$ 个，怎么来的呢？在构造子集时，对于每一个原集合中的元素，都有 “选” 或 “不选” 两种情况，根据乘法原理，就是 $2^n$ 个；本体就依照这个思路，并从两种不同的角度出发构造子集

## 解题思路

- 从输入的角度出发：我认为这个角度是最直观的，就是[[递归]]遍历原集合，用 “选与不选” 构造子集，用一个变量记录进度，递归终点就是递归进度与原集合大小相等，达到终点[[回溯]]
- 从结果的角度出发：这次考察每一个子集，枚举子集中会出现哪一些元素

## 代码实现

- 选与不选：

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> ans;
        vector<int> path;
        int n = nums.size();
        auto dfs = [&](this auto&& dfs, int i) -> void {
            if (i == n) {
                ans.emplace_back(path);
                return;
            }
            // 不选就空过一个元素
            dfs(i + 1);
            
            path.emplace_back(nums[i]);
            dfs(i + 1);
            path.pop_back();
        };
        dfs(0);
        return ans;
    }
};
```

- 枚举子集：

```cpp
class Solution {
public:
    vector<vector<int>> subsets(vector<int>& nums) {
        vector<vector<int>> ans;
        vector<int> path;
        int n = nums.size();
        auto dfs = [&](this auto&& dfs, int i) -> void {
            ans.emplace_back(path);
            for (int j = i; j < n; j++) {
                path.emplace_back(nums[j]);
                dfs(j + 1);
                path.pop_back();
            }
        };
        dfs(0);
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(n$2^n$)**

主要开销来自递归次数 O($2^n$) 和复制 path O(n) 需要的时间，其中 n 为 nums 的长度

### 空间复杂度：**O(n)**

## 总结 / 错误反思

思考递归过程时，想个一层就够了，只要把递归终点和递归步骤写对，剩下的都是一样的，自然就对了；我觉得也可以从递归终点开始想，往上回一层，剩下的都是一样的
