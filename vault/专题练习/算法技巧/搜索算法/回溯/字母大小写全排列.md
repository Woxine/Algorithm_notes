[字母大小写全排列](https://leetcode.cn/problems/letter-case-permutation/)
## 代码实现

```cpp
class Solution {
public:
    vector<string> letterCasePermutation(string s) {
        vector<string> ans;
        string path = s;
        int n = s.size();
        auto dfs = [&](this auto&& dfs, int i) -> void {
            if (i == n) {
                ans.emplace_back(path);
                return;
            }
            dfs(i + 1);
            if (isalpha(path[i])) {
                path[i] ^= ' ';
                dfs(i + 1);
                path[i] ^= ' ';
            }
        };
        dfs(0);
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(n$2^n$)**

### 空间复杂度：**O(n$2^n$)**

## 知识补充

`path[i] ^= ' ';`这行代码什么意思？

大小写字母的 ASCLL 码之间刚好相差 32，而空格的 ASCLL 刚好是 32，所以将字符与空格进行异或运算能达到加减32的效果
