[二叉树的所有路径](https://leetcode.cn/problems/binary-tree-paths/)
## 题目拆解 / 题意分析

## 解题思路

递归 + dfs：深度优先搜索递归遍历整个二叉树，找到所有可能路径，递归边界是空节点

## 代码实现

- 递归实现，road 作为参数：

```cpp
class Solution {
public:
    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> ans;
        auto dfs = [&](this auto&& dfs, TreeNode* node, string road) -> void {
            if (!node) {
                return;
            }
            road += to_string(node->val);
            if (!node->left && !node->right) {
                ans.push_back(road);
                return;
            }
            road += "->";
            dfs(node->left, road);
            dfs(node->right, road);
        };
        dfs(root, "");
        return ans;
    }
};
```

- 回溯实现：

```cpp
class Solution {
public:
    vector<string> binaryTreePaths(TreeNode* root) {
        vector<string> ans;
        string road;
        auto dfs = [&](this auto&& dfs, TreeNode* node) -> void {
            if (!node) {
                return;
            }
            // 记录当前状态（回溯点）
            int originalLength = road.length();
            if (!road.empty()) {
                road += "->";
            }
            road += to_string(node->val);
            // 到达叶子节点，保存路径
            if (!node->left && !node->right) {
                ans.push_back(road);
            } else {
	            // 继续探索
                dfs(node->left);
                dfs(node->right);
            }
            // 回溯：恢复到进入当前节点前的状态
            road.resize(originalLength);
        };
        dfs(root);
        return ans;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n² log U)**

这里的时间复杂度主要来自**访问节点**和**操作字符串**，其中 n 是二叉树的节点个数，U 是节点绝对值的最大值。最坏的情况下，二叉树是扫帚形，即一条 O(n) 个节点的链加上一棵包含 O(n) 个叶子的（完全）二叉树。在这种情况下，由于每个节点值的字符串的长度为 O(logU)，所以路径长度为 O(nlogU)。我们会把 O(n) 个长为 O(nlogU) 的 path 加入答案

### 空间复杂度：**O(n² log U) 或 O(n log U)**

暴力递归和回溯的区别就在于，递归在每个栈帧都会存储一个路径，而回溯只使用一个单独的变量
