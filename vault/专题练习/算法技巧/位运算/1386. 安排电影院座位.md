[1386. 安排电影院座位](https://leetcode.cn/problems/cinema-seat-allocation/)
## 题目拆解 / 题意分析

对于每一行，只有一种情况能坐下 2 组，有三种情况能坐下 1 组，其余情况一组都坐不下
对于每一行分类讨论即可

## 解题思路

[[哈希表]] + [[位运算]] + [[贪心算法]]：是否被预定是一种二元状态，可以用二进制数来存储；哈希表的键是行号，值是表示座位存储情况的二进制数；然后用位运算统计空座位的情况

## 代码实现

```cpp
class Solution {
public:
    int maxNumberOfFamilies(int n, vector<vector<int>>& reservedSeats) {
        unordered_map<int, int> seats;
        for (auto& r : reservedSeats) {
            int seatNum = r[1];
            int rowNum = r[0];
            if (seatNum >= 2 && seatNum <= 9) {
	            // 只统计座位 2-9
                seats[rowNum] |= 1 << (seatNum - 2);
            }
        }

        int two_groups = n - seats.size();
        int ans = 2 * two_groups;
        for (auto& [_, s] : seats) {
	        // 0b 表示二进制数
	        // 只有 s 的最后 4 位都是 0，(s & 0b1111) == 0 才为真
            if ((s & 0b1111) == 0 || (s & 0b111100) == 0 ||
                (s & 0b11110000) == 0) {
                ans++;
            }
        }
        return ans;
    }
};
```
