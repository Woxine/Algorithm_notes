[数位和相等数对的最大和](https://leetcode.cn/problems/max-sum-of-a-pair-with-equal-sum-of-digits/)
## 解题思路

跟上一题的思路差不多

```cpp
class Solution {
public:
    int maximumSum(vector<int>& nums) {
	    // 最多 9 个 9 相加
        int ans = -1, map[82]{}; 
        for (int n : nums) {
            int sum = 0;
            for (int i = n; i; i /= 10) {
                sum += i % 10;
            }
            if (map[sum]) {
                ans = max(ans, n + map[sum]);
            }
            map[sum] = max(map[sum], n);
        }
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(nlogU)**

其中 n 为 nums 的长度，U=max(nums)

### 空间复杂度：**O(DlogU)**
