[好数对的数目](https://leetcode.cn/problems/number-of-good-pairs/)
## 解题思路

- [[枚举右，维护左]]：在枚举的过程中记录同一个数的出现次数，每次出现一个新的相等的数时，它的左边有多少个相等的数（用[[哈希表]]来记录这个值），就会有多少对“好数对”

```cpp
class Solution {
public:
    int numIdenticalPairs(vector<int>& nums) {
        int ans = 0;
        unordered_map<int, int> map;
        // 先累加，后自增
        for (int n : nums) {
            ans += map[n]++;
        }
        return ans;
    }
};
```
