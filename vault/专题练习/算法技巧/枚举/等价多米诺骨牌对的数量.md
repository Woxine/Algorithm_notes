[等价多米诺骨牌对的数量](https://leetcode.cn/problems/number-of-equivalent-domino-pairs/description/)
## 解题思路

用[[哈希表]]维护特征相同的数组数量，累加起来

```cpp
class Solution {
public:
    int numEquivDominoPairs(vector<vector<int>>& dominoes) {
        int ans = 0;
        int map[10][10];
        for (auto& n : dominoes) {
	        auto [a, b] = minmax(n[0], n[1]);
            ans += map[a][b]++;
        }
        return ans;
    }
};
```

## 新知识点

函数`minmax(a,b)`可以同时获取两个数之间的最大值和最小值
