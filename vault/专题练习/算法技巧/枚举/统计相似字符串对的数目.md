[统计相似字符串对的数目](https://leetcode.cn/problems/count-pairs-of-similar-strings/)
## 解题思路

- [[枚举右，维护左]]：这道题我一开始想要创建一个`unordered_map<vector<int>, int> count`的[[哈希表]]来维护每个字符串的字母构成，但是不行，没这种写法；然后我又想能不能搞一个26位的二进制 0 ，出现了相应字母，对应位上的 0 就改成 1，但是不知道怎么实现，于是就找到了灵神题解：

```cpp
class Solution {
public:
    int similarPairs(vector<string>& words) {
        int ans = 0;
        unordered_map<int, int> count;
        for (auto& word : words) {
            int digit = 0;
            for (char c : word) {
	            // 1 << (c - 'a') 能得到一个对应位为 1 的二进制数
	            // 然后进行按位与 |= 就能将 digit 中对应位改为 1
                digit |= 1 << (c - 'a');
            }
            // 记录相同字母构成数量
            ans += count[digit]++;
        }
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(nm)**

其中 n 是 words 的大小，m 是最长的字符串的大小

### 空间复杂度：**O(n)**
