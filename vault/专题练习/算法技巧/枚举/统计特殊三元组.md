[统计特殊三元组](https://leetcode.cn/problems/count-special-triplets/)
## 解题思路

- [[枚举中间]]：对于三元组问题，通常[[枚举中间]]。这道题中，我们枚举`nums[j]`，只要知道左右两边有多少数等于`nums[j] * 2`就行了，如何统计这个值呢？我们可以用[[哈希表]]来统计一个数的出现次数，在枚举过程中，不断更新哈希表即可

```cpp
class Solution {
public:
    int specialTriplets(vector<int>& nums) {
        unordered_map<int, int> suf;
        // 遍历整个数组，将所有元素的出现次数统计下来作为后缀数组
        for (int n : nums) {
            suf[n]++;
        }
        long long ans = 0;
        unordered_map<int, int> pre;
        for (int n : nums) {
	        // 开始枚举，右边的元素不断减少
            suf[n]--;
            ans += (long long)pre[n*2] * suf[n*2];
            // 左边的元素不断增多
            pre[n]++;
        }
        return ans % 1000000007;
    }
};
```
