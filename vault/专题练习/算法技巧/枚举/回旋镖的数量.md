[回旋镖的数量](https://leetcode.cn/problems/number-of-boomerangs/)
## 解题思路

- [[枚举中间]]嵌套[[枚举右，维护左]]：题目要求统计到 i 的距离相同的 j 和 k 有多少（考虑顺序），其实就是再求到 i 距离相同的点有多少对。对于这样一个三变量问题，可以在外层循环先枚举中间（i），在内层循环枚举 j ，同时用哈希表维护到 i 的距离相同的点的个数，最后累加得到结果。由于对位置没有要求，所以 j 和 k 没有区别

```cpp
class Solution {
public:
    int numberOfBoomerangs(vector<vector<int>>& points) {
        int ans = 0;
        // 记录到 i 距离相同的点的数量
        unordered_map<int, int> cnt;
        // 枚举中间
        for (auto& i : points) {
            cnt.clear();
            // 枚举 j （k）
            for (auto& j : points) {
                int dis = (i[0] - j[0]) * (i[0] - j[0]) +
                          (i[1] - j[1]) * (i[1] - j[1]);
                ans += cnt[dis]++;
            }
        }
        // 考虑顺序，结果乘以2
        return ans * 2;
    }
};
```

### 时间复杂度：**O($n^2$)**

### 空间复杂度：**O(n)**

## 总结

意识到 j 和 k 本质上没区别很关键，这样一来就通过”枚举中间“和”枚举右，维护左“将一个三变量问题转化为单变量问题
