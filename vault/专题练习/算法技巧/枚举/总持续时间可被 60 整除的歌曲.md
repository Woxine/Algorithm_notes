[总持续时间可被 60 整除的歌曲](https://leetcode.cn/problems/pairs-of-songs-with-total-durations-divisible-by-60/)

## 解题思路

- [[枚举右，维护左]]：在遍历过程中，我们需要找到“当前数**模 60 的结果**与左边有多少个数**模 60 的结果**相加得 0 ”，即`(time[i] + time[j]) % 60 == 0 -> time[i] % 60 + time[j] % 60 == 0`。可以发现，将两个数联系起来的量就是**模 60 的结果**，所以我们使用[[哈希表]]来记录当前数模 60 的结果，用 ans 累加符合条件的值

```cpp
class Solution {
public:
    int numPairsDivisibleBy60(vector<int>& time) {
        int ans = 0;
        unordered_map<int, int> mod;
        for (int i = 0; i < time.size(); i++) {
	        // 记录模 60 的结果
            int m = time[i] % 60;
            ans += mod[60 - m];
            // 特别的，如果本来就能整除，ans 会累加 mod[0] 的值
            // 所以如果 m == 0，要特别处理
            mod[m == 0 ? 60 : m]++;
        }
        return ans;
    }
};
```
