[必须拿起的最小连续卡牌数](https://leetcode.cn/problems/minimum-consecutive-cards-to-pick-up/)
## 解题思路

- [[滑动窗口]]：用[[哈希表]]记录当前值的下标，出现相同元素时更新下标和手牌长度

```cpp
class Solution {
public:
    int minimumCardPickup(vector<int>& cards) {
        int left = 0, ans = INT_MAX;
        unordered_map<int,int> map;
        for (int right = 0; right < cards.size(); right++) {
            if(map.find(cards[right]) != map.end()){
                left = map[cards[right]];
                ans = min(ans,right-left+1);
            }
            map[cards[right]] = right;
        }
        return ans == INT_MAX ? -1 : ans;
    }
};
```

- [[枚举右，维护左]]

```cpp
class Solution {
public:
    int minimumCardPickup(vector<int>& cards) {
        int ans = INT_MAX;
        unordered_map<int,int> map;
        for (int i = 0; i < cards.size(); i++) {
            if(map.count(cards[i])){
                ans = min(ans,i-map[cards[i]]+1);
            }
            map[cards[i]] = i;
        }
        return ans == INT_MAX ? -1 : ans;
    }
};
```

## 总结

感觉这里的不定长滑窗没有起到什么作用，left 只是记录元素上一次出现的位置，并没有“滑动”，而且枚举更简洁
