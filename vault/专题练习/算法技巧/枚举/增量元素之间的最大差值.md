[增量元素之间的最大差值](https://leetcode.cn/problems/maximum-difference-between-increasing-elements/)
## 解题思路

- [[双指针]]：双指针遍历

```cpp
class Solution {
public:
    int maximumDifference(vector<int>& nums) {
        int ans = 0, l = 0;
        // 枚举右端点
        for (int r = 0; r < nums.size(); r++) {
	        // 移动左端点到合法位置
            while (nums[l] > nums[r] && l < r) {
                l++;
            }
            // 更新答案
            ans = max(ans, nums[r] - nums[l]);
        }
        // 如果到最后 ans 还是 0，说明没有满足要求的数对，返回 -1
        return ans ? ans : -1;
    }
};
```

- [[枚举右，维护左]]：记录当前值之前的最小值，求最大差值

```cpp
class Solution {
public:
    int maximumDifference(vector<int>& nums) {
        int ans = 0, pre_min = INT_MAX;
        for (int x : nums) {
	        // 更新答案
            ans = max(ans, x - pre_min);
            // 更新最小值
            pre_min = min(pre_min, x);
        }
        return ans ? ans : -1;
    }
};
```
