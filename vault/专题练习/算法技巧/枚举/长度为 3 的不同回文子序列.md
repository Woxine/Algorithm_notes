[长度为 3 的不同回文子序列](https://leetcode.cn/problems/unique-length-3-palindromic-subsequences/)
## 解题思路

- [[枚举中间]]：回文数是对称的，所以我们需要枚举中间的那个字符，查找两边存在多少对相同的字符就行。同时题目要求构成相同的子序列只计入一次，所以我们只需要记录”这个子序列出现过“，最后再来计数，而不需要每出现一个满足要求的子序列就记录一次.这里用[[位运算]]记录，跟[[统计相似字符串对的数目]]里的方法是一样的

```cpp
class Solution {
public:
    int countPalindromicSubsequence(string s) {
        int pre[26] = {0};
        int suf[26] = {0};
        // 32位无符号整数数组
        uint32_t has[26] = {0}; 
        // 初始化后缀数组，统计从第二个字符开始的所有字符
        for (int i = 1; i < s.size(); i++) {
            suf[s[i] - 'a']++;
        }
        for (int i = 1; i < s.size() - 1; i++) {
	        // 将前一个字符加入前缀统计
            pre[s[i-1] - 'a']++;
            // 从后缀中移除当前字符（因为当前字符作为中间字符）
            suf[s[i] - 'a']--;
            for (int j = 0; j < 26; j++) {
                if (pre[j] && suf[j]) {
	                // 统计以当前字符为中心，出现过的满足条件的字符
                    has[s[i] - 'a'] |= 1 << j;
                }
            }
        }
        int ans = 0;
        // 统计所有情况下 1 的数量
        for (int i = 0; i < 26; ++i) {
            ans += __builtin_popcount(has[i]);
        }
        
        return ans;
    }
};
```

### 时间复杂度：**O(n)**

### 空间复杂度：**O(1)**
