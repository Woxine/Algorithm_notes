[可获得的最大点数](https://leetcode.cn/problems/maximum-points-you-can-obtain-from-cards/description/)

## 解题思路

这道题本质上仍然是一道定长[[滑动窗口]]题，但是它的思路很有意思

### 逆向思维

想要找到`k`张牌的点数最大，只要保证剩下的`n-k`张牌的点数最小就行了，而由于这`k`张牌只能在首尾选，那么剩下的`n-k`张牌肯定是**连续的子序列**，那么我们只需要使用常规的定长滑动窗口解决就行了。

```cpp
class Solution {
public:
    int maxScore(vector<int>& cardPoints, int k) {
        int n = cardPoints.size();
        int m = n - k;
        int s = reduce(cardPoints.begin(), cardPoints.begin() + m);
        // 这里的reduce函数在求容器前m项的和
        int min_s = s;
        for (int i = m; i < n; i++){
            s += cardPoints[i] - cardPoints[i - m];
            // 这是更新部分，相等于加上当前数然后减去最左边的
            // 这里能够简写的原因是先前reduce的部分帮我们省去了初始化窗口的过程
            min_s = min(min_s,s);
        }
        return reduce(cardPoints.begin(),cardPoints.end()) - min_s;
    }
};
```

[[逆向思维]]帮助我们找到的熟悉的模式，也就是找到目标子序列，然后将窗口从左往右移动来遍历数组，找到最小的和，然后用总和减掉它就行了

### 正向思维

原题要求我们只能从首位拿牌，这导致整个窗口被分成了两部分。但实际上我们需要捕捉到定长滑动窗口的两个最基本特征：**连续**和**定长**。我们一定会拿`k`张牌，**定长**是确定的，那么**连续**呢？如果将整个数组看成**一个环**，也就**不存在什么首位之分**了，在上面任意找一个窗口**都是连续的**。这里整个窗口的移动可以看成（用数组下标表示）：
- 0到k-1
- 0到k-2 和 n-1
- 0到k-3 和 n-2到n-1
- 0到k-4 和 n-3到n-1
- ……
- 0到k-i 和 n-i到n-1

```cpp
class Solution {
public:
    int maxScore(vector<int>& cardPoints, int k) {
        int s = reduce(cardPoints.begin(), cardPoints.begin() + k);
        int ans = s, n = cardPoints.size();
        for (int i = 0; i < k; i++){
            s += cardPoints[n - i] - cardPoints[k - i];
            ans = max(ans,s);
        }
        return ans;
    }
};
```

总之，这个窗口是从右往左的，左边那一端从数组尾部接上继续往左；当然，从左往右也是一样的道理，从`n-k`到`n-1`开始就行
