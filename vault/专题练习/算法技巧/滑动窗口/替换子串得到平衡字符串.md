[替换子串得到平衡字符串](https://leetcode.cn/problems/replace-the-substring-for-balanced-string/)
## 解题思路

目标字符串由`代替换的子串`以及剩下的部分组成，想要得到一个合法的字符串，需要保证每种字符在`代替换的子串`以及其余部分中的数量和为`m = n / 4`，即

$$
count(字符) = replace + remain=m
$$
而replace（代替换子串中字符的数量）和remain（其余部分字符的数量）都一定是自然数，这就意味着：**无论是`代替换的子串`内还是`代替换的子串`外，每一种字符的数量都不能超过`m`**

回顾[[滑动窗口]]的基本模式：

- 元素入队，达成所要**条件**
- **条件**被打破
- 元素出队，维护端口，重新满足**条件**

这个最关键的**条件**我们已经找到了，就是**无论是`代替换的子串`内还是`代替换的子串`外，每一种字符的数量都不能超过`m`

```cpp
class Solution {
public:
    int balancedString(string s) {
	    // 这样的数组声明方式看上去有点奇怪，因为这里将‘A’作为一个整数来用了
	    // 这样就形成了一个类似“字典”的东西，毕竟每个字符的ASCLL码是单独的
	    // 这里用哈希表也行，但是要慢一些
        int c['A' + 26];
        // 先统计一次总量
        for (char count : s) {
            c[count]++;
        }
        int n = s.length(), m = n / 4;
        // 特判是否已经满足，因为ans是从n开始的
        if (c['Q'] == m && c['W'] == m && c['E'] == m && c['R'] == m) {
            return 0;
        }
        int ans = n, l = 0;
        for (int r = 0; r < n; r++) {
            c[s[r]]--;
            // 每一种字符的数量都不能超过m
            while (c['Q'] <= m && c['W'] <= m && c['E'] <= m && c['R'] <= m) {
                ans = min(ans, r - l + 1);
                c[s[l++]]++;
            }
        }
        return ans;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n)**

虽然代码包含两个循环，但它们是顺序关系，所以是O(n)

### 空间复杂度：**O(1)**

- 空间复杂度主要来自：
    1. 字符计数数组`c['A' + 26]`，这是一个固定大小的数组（大小为 'A'+26，约 100 左右），属于常数级空间。
    2. 几个整数变量（`n`、`m`、`ans`、`l`、`r`等），同样是常数级空间。
- 因此，整体空间复杂度为**O(1)**（常数级），不随输入规模变化而变化。
