[几乎唯一子数组的最大和](https://leetcode.cn/problems/maximum-sum-of-almost-unique-subarray/)

## 解题思路

这道题的关键在如何确定子数组中有多少个**只出现过一次的元素**，而提到查找某一的特殊元素或者**统计某元素出现的次数**，我们能想到哈希表。我们可以在滑动窗口更新时将元素存入哈希表，如果哈希表中的元素数量超过`m`，就符合条件。

```cpp
class Solution {
public:
    long long maxSum(vector<int>& nums, int m, int k) {
        long long ans = 0, sum = 0;
        unordered_map<int,int> count;
        for (int i=0;i<nums.size();i++){
            sum += nums[i];
            count[nums[i]]++;
            int left = i-k+1;
            if (left < 0){
                continue;
            }
            if (count.size() >= m){
                ans = max(ans,sum);
            }
            int gone = nums[left];
            sum -= gone;
            if (--count[gone] == 0){
                count.erase(gone);
            }
        }
        return ans;
    }
};
```

这里哈希表的键就是窗口中出现过的元素，值对应的就是元素出现的次数。还需要注意的是元素出窗口时的移除条件
