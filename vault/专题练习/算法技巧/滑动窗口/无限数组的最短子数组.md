[无限数组的最短子数组](https://leetcode.cn/problems/minimum-size-subarray-in-infinite-array/)
## 解题思路

我们要从 `infinite_nums` 中找出满足 **元素和** 等于 `target`的一个**子序列**，而这个`infinite_nums`是由无数个`nums`构成的，将`nums`中的元素和记作`total`，我们可以得到：构成`target`的子序列肯定是由k个`nums`和一个余数构成的（k可以等于零），即：
$$
target=k*tatal+remain
$$
其中这个`remain`等于`target % total`

```cpp
class Solution {
public:
    int minSizeSubarray(vector<int>& nums, int target) {
        int l = 0, ans = INT_MAX, n = nums.size();
        // 因为待会要统计target中有多少个nums，需要先将总和算出来
        long long total = reduce(nums.begin(), nums.end(), 0LL);
        long long sum = 0;
        // 这里在求remain的长度
        // 终点设成r < n * 2的原因是remain不会超出这个范围
        // 根据鸽巢原理，假如remain超出了这个范围，就一定会有一个nums被包含在内
        // 矛盾，所以只要遍历到r < n * 2就够了，无需更多
        for (int r = 0; r < n * 2; r++) {
            sum += nums[r % n];
            while (sum > target % total) {
                sum -= nums[l % n];
                l++;
            }
            if (sum == target % total) {
                ans = min(ans, r - l + 1);
            }
        }
        return ans == INT_MAX ? -1 : target / total * n + ans;
    }
};
```
