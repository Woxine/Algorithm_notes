[删除子数组的最大得分](https://leetcode.cn/problems/maximum-erasure-value/)
## 解题思路

这道题其实和[[10.无重复字符的最长字串]]是一样的，但是这里我们不需要用[[哈希表]]，而是可以用更简单的哈希集合（`unordered_set`），哈希集合可以快速的判断一个元素是否存在，用于去重

- 哈希表解法

```cpp
class Solution {
public:
    int maximumUniqueSubarray(vector<int>& nums) {
        int sum = 0, ans = 0, l = 0;
        unordered_map<int, int> map;
        for (int r = 0; r < nums.size(); r++) {
            sum += nums[r];
            map[nums[r]]++;
            while (map[nums[r]] > 1) {
                map[nums[l]]--;
                sum -= nums[l++];
            }
            ans = max(ans, sum);
        }
        return ans;
    }
};
```

- 哈希集合解法：

```cpp
class Solution {
public:
    int maximumUniqueSubarray(vector<int>& nums) {
        int sum = 0, ans = 0, l = 0;
        unordered_set<int> s;
        // 迭代器，遍历nums中的所有元素
        for (int x : nums) {
	        // 先判断集合中是否存在当前元素，有的话直接开始维护左端点
            while (s.contains(x)) {
                s.erase(nums[l]);
                sum -= nums[l++];
            }
            // 之后再添加新元素，保证集合中没有重复元素
            s.insert(x);
            sum += x;
            ans = max(ans, sum);
        }
        return ans;
    }
};
```

这里灵神还提供了一种适用**布尔数组**的方法：

```cpp
class Solution {
public:
    int maximumUniqueSubarray(vector<int>& nums) {
        int mx = ranges::max(nums);
        int sum = 0, ans = 0, l = 0;
        vector<int8_t> has(mx + 1);
        for (int x : nums) {
            while (has[x]) {
                has[nums[l]] = false;
                sum -= nums[l++];
            }
            has[x] = true;
            sum += x;
            ans = max(ans, sum);
        }
        return ans;
    }
};
```
## 新知识点

这个**布尔数组**相当于用空间换时间了，先开一个大数组，然后只需要维护true和false就行，拥有O(1)的查询速度，操作简单，不用担心哈希冲突

但是前提是**数据范围不能太大**，哈希表更通用
