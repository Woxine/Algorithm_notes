[拆炸弹](https://leetcode.cn/problems/defuse-the-bomb/description/)

## 解题思路

这道题套两层循环直接暴力解也行，但是我们可以用[[滑动窗口]]得到一个O(n)的解

经过分析可以发现，窗口的长度的固定的，而且无论是`k>0`还是`k<0`，窗口总是向右移动，所以现在就剩下如何**找到窗口的端点**以及如何**更新数据**

```cpp
class Solution {
public:
    vector<int> decrypt(vector<int>& code, int k) {
        int n = code.size();
        vector<int> ans(n);
        // k>0和k<0的情况不同，起始点也不同
        int r = k > 0 ? k + 1 : n;
        k = abs(k);
        // 初始化窗口
        int s = reduce(code.begin() + r - k, code.begin() + r);
        for (int i = 0; i < n; i++) {
            ans[i] = s;
            // 更新数据，循环数组取模运算
            // 特别的，当k == 0时，s += 0. 所以不用特判
            s += code[r % n] - code[(r - k) % n];
            r++;
        }
        return ans;
    }
};
```

## 总结

再次回顾定长滑动窗口的套路：
- 确认窗口长度
- 定位窗口端点和移动方式
- 初始化窗口
- 更新数据
