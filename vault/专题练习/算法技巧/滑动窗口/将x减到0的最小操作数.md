[将 x 减到 0 的最小操作数](https://leetcode.cn/problems/minimum-operations-to-reduce-x-to-zero/)
## 解题思路

这道题要求从数组的两端获取元素，我首先想到[[双指针]]，可以用对向[[双指针]]向中间收缩，但是有点麻烦。这里可以用[[逆向思维]]，想要两端长度最短，相当于使中间连续的子数组最长就行了。这样一来问题就变成了：找到一个最长的子数组，使得它的元素和刚好是sum(元素总和) - x

```cpp
class Solution {
public:
    int minOperations(vector<int>& nums, int x) {
	    // 先算出除去x的部分
        int remain = reduce(nums.begin(), nums.end()) - x;
        // 如果全部元素加起来都不够，返回-1
        if (remain < 0) {
            return -1;
        }
        int ans = -1, l = 0, s = 0, n = nums.size();
        for (int r = 0; r < n; r++) {
            s += nums[r];
            // 维护子数组
            while (s > remain) {
                s -= nums[l++];
            }
            if (s == remain) {
                ans = max(ans, r - l + 1);
            }
        }
        // 三目运算符，最终答案是n-ans
        return ans < 0 ? -1 : n - ans;
    }
};
```
