[考试的最大困扰度](https://leetcode.cn/problems/maximize-the-confusion-of-an-exam/)
## 解题思路

反转至多k个T或F得到满足条件的字串，就是说找到至多包含k个T或F的最长字串有多长？
又是这种找最长子串的问题，用[[滑动窗口]]就很合适

```cpp
class Solution {
public:
    int maxConsecutiveAnswers(string answerKey, int k) {
        int ans = 0, l = 0;
        // 用哈希表计数
        unordered_map<char, int> count(2);
        for (int r = 0; r < answerKey.length(); r++) {
            count[answerKey[r]]++;
            // 维护子串
            while (count['T'] > k && count['F'] > k) {
                count[answerKey[l++]]--;
            }
            // 更新答案
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

通过了，但是很慢，一看题解傻眼了：

```cpp
class Solution {
public:
    int maxConsecutiveAnswers(string answerKey, int k) {
        int ans = 0, l = 0, count[2]{};
        for (int r = 0; r < answerKey.length(); r++) {
            count[answerKey[r] >> 1 & 1]++;
            while (count[0] > k && count[1] > k) {
                count[answerKey[l++] >> 1 & 1]--;
            }
            ans = max(ans, r - l + 1);
        }
        return ans;
    }
};
```

不是这个`count[answerKey[r] >> 1 & 1]++;`是什么玩意？
'T' 的 ASCII 码是 84（二进制 1010100），'F' 是 70（二进制 1000110）。  
当右移 1 位再与 1 相与时：

- 'T' >> 1 & 1 结果为 0
- 'F' >> 1 & 1 结果为 1  

所以这行代码实际上是在统计 'T' 和 'F' 的数量，分别存放在 cnt [0] 和 cnt [1] 中
## 新知识点

在操作字符时可以灵活运用ASCII码，不光是十进制，二进制也可以考虑进去

## 总结

这道题的关键就在于，将”**最多修改k次，得到连续相同字符的字串**“，转化成”**找到至多包含k个T或F的最长字串有多长**“，然后用滑动窗口解就行
