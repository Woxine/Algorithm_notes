[删掉一个元素以后全为 1 的最长子数组](https://leetcode.cn/problems/longest-subarray-of-1s-after-deleting-one-element/)
## 解题思路

又是一道找符合条件的**子序列**的题，这里用不定长[[滑动窗口]]就很合适

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
	    // d用来存储删除的数量
        int ans = 0, d = 0, l = 0;
        for (int r = 0; r < nums.size(); r++) {
	        // 如果当前数是0，就直接标记为删除
            if (nums[r] == 0) {
                d++;
            }
            // 只能删一个，如果被标记的0的数量大于1
            // 那就更新左指针到上一个零之后
            while (d > 1) {
                if (nums[l++] == 0) {
                    d--;
                }
            }
            // 更新答案（包含被标记删除的0）
            ans = max(ans, r - l + 1);
        }
        // 无论如何都要删一个
        return ans-1;
    }
};
```

总体思路没什么变化，枚举右指针，每当一个新的元素进入**队列**，判断当前状况，维护左指针，就是在重复这样一个循环：
- 枚举右指针元素入队来达到条件
- 由于不符合条件的元素入队而破坏条件
- 维护左指针出队来重新使队列符合条件

“优化”后的代码（稍微短了一点）：

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int ans = 0, d = 0, l = 0;
        for (int r = 0; r < nums.size(); r++) {
            d += 1 - nums[r];
            while (d > 1) {
                d -= 1 - nums[l++];
            }
            ans = max(ans, r - l);
        }
        return ans;
    }
};
```

## 总结

这道题就很好地体现了灵神提到的“**枚举右，维护左**”的算法思想。在不定长滑动窗口问题中，窗口的左右两端都不确定，而我们不喜欢双变量问题，通过每次枚举右端点的方式将右端点先定下来，这样一来就变成了一个单变量的问题
