[最短且字典序最小的美丽子字符串](https://leetcode.cn/problems/shortest-and-lexicographically-smallest-beautiful-string/)
## 解题思路

这道题的大致流程就是：
- 找到含有k个1的字符串
- 更新字符串，找到更短的；如果一样长，就比较字典序，找到更小的
像这样维护一个动态的子序列可以用[[滑动窗口]]来解

```cpp
class Solution {
public:
    string shortestBeautifulSubstring(string s, int k) {
        string ans = "";
        int count = 0, l = 0, min_length = INT_MAX;
        for (int r = 0; r < s.length(); r++) {
	        // 更新右指针，元素入队
            count += (s[r] - '0');
            // 当出现符合要求的字串后，更新字串
            // 如果没有符合要求的字串，ans会是空串，无需特判
            while (count == k) {
                int currentLen = r - l + 1;
                string current = s.substr(l, currentLen);
                if (currentLen < min_length) {
                    min_length = currentLen;
                    ans = current;
                } else if (currentLen == min_length) {
                    if (current < ans) {
                        ans = current;
                    }
                }
                // 维护左指针，元素出队
                count -= (s[l++] - '0');
            }
        }
        return ans;
    }
};
```

“优化”一下：

```cpp
class Solution {
public:
    string shortestBeautifulSubstring(string s, int k) {
        string ans = "";
        int count = 0, l = 0, ml = INT_MAX;
        for (int r = 0; r < s.length(); r++) {
            count += s[r] - '0';
            while (count == k) {
                string c = s.substr(l, r - l + 1);
                if (c.length() < ml || c.length() == ml && c < ans) {
                    ml = c.length();
                    ans = move(c);
                }
                count -= s[l++] - '0';
            }
        }
        return ans;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n²)**

- **外层循环**：右指针 `r` 从 0 遍历到 `n-1`（`n` 为字符串长度），共执行 `n` 次。
- **内层循环**：左指针 `l` 最多从 0 移动到 `n-1`，整体累计移动 `n` 次（不会重复移动），因此内层循环总执行次数为 `O(n)`。

### 空间复杂度： **O(n)**

- 算法中主要的空间消耗来自存储子串 `current` 和结果 `ans`，它们的最大长度均为 `n`（整个字符串）。
- 其他变量（`count`、`l`、`r`、`min_length` 等）均为常数级空间消耗。

## 新知识点

`s.substr(a,b)`可以获取字符串`s`从下标a到b的一个字子串
`a = move(b)`可以将b“移动”到a中，然后b变为空，适用于临时变量，减少赋值成本
