[子数组最大平均数 Ⅰ](https://leetcode.cn/problems/maximum-average-subarray-i/)

## 解题思路

```cpp
class Solution {
public:
    double findMaxAverage(vector<int>& nums, int k) {
        int maxs = INT_MIN, sum = 0;
        for (int i=0;i<nums.size();i++){
            sum += nums[i];
            if (i<k-1){
                continue;
            }
            maxs = max(sum,maxs);
            sum -= nums[i-k+1];
        }
        return (double) maxs/k;
    }
};
```

这也是一道很简单的定长[[滑动窗口]]题，符合固定套路：
- 获得第一个窗口的信息
- 不断右移并更新窗口信息
