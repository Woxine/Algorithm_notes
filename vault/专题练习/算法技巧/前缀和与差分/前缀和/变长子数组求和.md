[变长子数组求和](https://leetcode.cn/problems/sum-of-variable-length-subarrays/)
## 解题思路

题目要求某个**子数组中所有元素的和**，就很适合用[[前缀和]]来写：

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums) {
        int n = nums.size();
        // 前缀和数组
        vector<int> profix(n + 1);
        for (int i = 0; i < n; i++) {
            profix[i + 1] = profix[i] + nums[i];
        }
        int ans = 0;
        for (int j = 0; j < n; j++) {
            ans += profix[j + 1] - profix[max(j - nums[j], 0)];
        }
        return ans;
    }
};
```

### 空间复杂度：**O(n+1)**
