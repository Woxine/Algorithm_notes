[统计范围内的元音字符串数](https://leetcode.cn/problems/count-vowel-strings-in-ranges/)
## 解题思路

要求**范围内***符合要求*的元素**有多少**，在更新[[前缀和]]的时候就要多一个条件：

```cpp
class Solution {
public:
	// 判断是否符合条件
    int isvowel(char c1, char c2) {
        if ((c1 == 'a' || c1 == 'e' || c1 == 'i' || c1 == 'o' || c1 == 'u') &&
            (c2 == 'a' || c2 == 'e' || c2 == 'i' || c2 == 'o' || c2 == 'u')) {
            return 1;
        }
        return 0;
    }
    vector<int> vowelStrings(vector<string>& words,
                             vector<vector<int>>& queries) {
        int q = queries.size(), w = words.size();
        vector<int> ans(q);
        vector<int> sum(w + 1);
        for (int i = 0; i < w; i++) {
	        // 符合要求才加 1 
            sum[i + 1] = sum[i] + isvowel(words[i][0], words[i].back());
        }
        for (int i = 0; i < q; i++) {
            ans[i] = sum[queries[i][1] + 1] - sum[queries[i][0]];
        }
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(max(w, q))**

### 空间复杂度：**O(max(w + 1, q))**

## 总结

感觉前缀和就是在为“**对容器中元素的同一操作进行存档**”，比如我**每天**都要**花一段时间**（元素）**锻炼身体**（操作），然后从月初开始，**每一天**都记录**这个月一共**锻炼了多少时间，如果我想知道从15号到20号（**某一区间**）锻炼了多少时间，就只需要将20号的记录减去14号的记录就行了
