[和为奇数的子数组数目](https://leetcode.cn/problems/number-of-sub-arrays-with-odd-sum/)
## 解题思路

先分析题目，要求**和为奇数的子数组**的数量，关键就在：如何求和？如何保证求出来的和为奇数？

我们已经知道如何通过[[前缀和]]来求子数组的和，但是题目**没有要求真的要得到这个值**，所以关键只在 **如何判断求出来的和是奇数**？

回到求[[前缀和]]的公式：`prefix[r] - prefix[l]`，要保证这个式子的结果是奇数，只要保证式子中两数奇偶性不同，但是我们总不能枚举`prefix[r]`，然后每次都遍历一遍之前的和吧，这样太慢了

我们最终要**计数**，而[[哈希表]]能够**记录统一种类型的值的数量**，所以我们只需要遍历[[前缀和]]，判断当前子数组的奇偶性，然后计算奇偶性不同的子数组的数量

```cpp
class Solution {
public:
    int numOfSubarrays(vector<int>& arr) {
	    // 这里的 odds 和 even 就相当于哈希表
        int ans = 0, odds = 0, even = 1, sum = 0;
        const int MOD = 1000000007;
        for (int& num : arr) {
            sum += num;
            // 先计算答案，然后当前的前缀和计入哈希表
            ans = (ans + (sum % 2 == 0 ? odds : even)) % MOD;
            (sum % 2 == 0 ? even : odds)++;
        }
        return ans;
    }
};
```

### 时间复杂度：**O(n)**

### 空间复杂度：**O(1)**
