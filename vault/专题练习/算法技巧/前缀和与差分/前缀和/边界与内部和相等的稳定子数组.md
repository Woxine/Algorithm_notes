[边界与内部和相等的稳定子数组](https://leetcode.cn/problems/stable-subarrays-with-equal-boundary-and-interior-sum/description/)
## 题目拆解 / 题意分析

还是先分析关系式，根据题意可以得到：`capacity[l] = capacity[r] = s[r] - s[l + 1]`
等价于同时满足：
$$
\begin{aligned}
&\text{capacity}[l] = \text{capacity}[r] \\
&\text{capacity}[l] + s[l + 1] = s[r]
\end{aligned}
$$
这里左和右的关系就很明显了，那么怎么保证数组至少有 3 个元素呢？

“为保证 `r − l + 1 ≥ 3`，可以在枚举 `r` 的同时，先查询哈希表更新答案，再把二元组 `(capacity[r − 1], capacity[r − 1] + s[r]) `加到哈希表，这样对于下一轮循环的 `r + 1` 来说，把添加的 `r − 1` 作为 `l`，与 `r + 1` 构成的子数组长度就是 `(r + 1) − (r − 1) + 1 = 3`，满足要求” —— 零茶山艾府

## 解题思路

[[前缀和]] + [[哈希表]] + [[枚举右，维护左]]：与[[和为 K 的子数组]]类似，枚举`s[r]`，统计有多少`s[r - 1]`满足上述式子，用哈希表存起来。不同的是，由于这次要满足两个式子，所以哈希表的键需要两个值来匹配

## 代码实现

```cpp
class Solution {
public:
    long long countStableSubarrays(vector<int>& capacity) {
        long long ans = 0, sum = capacity[0];
        map<pair<int, long long>, int> cnt;
        for (int r = 1; r < capacity.size(); r++) {
            ans += cnt[{capacity[r], sum}];
            cnt[{capacity[r - 1], capacity[r - 1] + sum}]++;
            sum += capacity[r];
        }
        return ans;
    }
};
```
