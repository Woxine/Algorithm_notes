[任意子数组和的绝对值的最大值](https://leetcode.cn/problems/maximum-absolute-sum-of-any-subarray/)
## 解题思路

我们已经了解了如何通过[[前缀和]]**快速求任意子数组的和**，也知道了如何求[[8.最大子数组和]]，那么如何找的**和的绝对值**最大的子数组呢？

还是先分析题目，我们知道前缀和求区间`[left, right]`子数组和的方式是`s[right + 1] - s[left]`，那么求绝对值就是`|s[right + 1] - s[left]|`，想要这个值最大，就要使`s[right + 1]`和`s[left]`的差距最大，那么一组数中哪两个数的差距最大？那就是**最大值**和**最小值**，要么用前者减去后者得到**最大的正数**，要么用后者减去前者得到**最小的负数**，然后更新这个答案

```cpp
class Solution {
public:
    int maxAbsoluteSum(vector<int>& nums) {
        int prefix = 0, min_pre = 0, max_pre = 0, ans = 0;
        for (int n : nums) {
            prefix += n;
            ans = max({ans, abs(prefix - min_pre), abs(prefix - max_pre)});
            min_pre = min(min_pre, prefix);
            max_pre = max(max_pre, prefix);
        }
        return ans;
    }
};
```
