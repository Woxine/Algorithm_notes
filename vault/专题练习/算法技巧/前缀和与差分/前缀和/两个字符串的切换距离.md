[两个字符串的切换距离](https://leetcode.cn/problems/shift-distance-between-two-strings/)
## 解题思路

根据题目描述，切换字符就两种方式，向前或向后，我们要做的就是遍历同时两个字符串，然后比较向前和向后切换的开销，将比较小的那个累加到答案中去，这里就有两个问题：

- 如何计算开销？
- 目标字符与当前字符的位置关系不同时，开销将如何变化？

因为切换操作是一种**连续多次的同一操作**，所以相当于计算子数组和，用[[前缀和]]就行，这里的重点就在于**前缀和元素表示的含义**是什么，一定要明确，否则就搞不清楚下标；同时还要判断绕一圈又回去的情况；

```cpp
class Solution {
public:
    long long shiftDistance(string s, string t, vector<int>& nextCost,
                            vector<int>& previousCost) {
        long long ans = 0;
        // prefix_n[i]表示下标为 0 的字符移动到下标为 i % 26 的字符的开销
        // prefix_p[i]表示下标为 i - 1 的字符移动到下标为 25 的字符的开销
        // 特别的，prefix[0] = 0
        long long prefix_p[27]{}, prefix_n[27]{};
        for (int i = 0; i < 26; i++) {
            prefix_n[i + 1] = prefix_n[i] + nextCost[i];
            prefix_p[i + 1] = prefix_p[i] + previousCost[i];
        }
        long long ncost, pcost;
        for (int i = 0; i < s.size(); i++) {
	        // 记录当前字符和目标字符的下标（0 ~ 25）
            int si = s[i] - 'a', ti = t[i] - 'a';
            // 至于为什么向后切换不需要 +1 而向前需要，画个图就行了
            if (ti >= si) {
                ncost = prefix_n[ti] - prefix_n[si];
                pcost = prefix_p[26] - (prefix_p[ti + 1] - prefix_p[si + 1]);
            } else {
                ncost = prefix_n[26] - (prefix_n[si] - prefix_n[ti]);
                pcost = prefix_p[si + 1] - prefix_p[ti + 1];
            }
            ans += min(ncost, pcost);
        }
        return ans;
    }
};
```

灵神版本：通过倍长解决了循环问题，同时简化了判断逻辑。我本来也想过如果目标字符下标在当前字符下标的左边，就给它加个 26，但就是没想到倍长

```cpp
class Solution {
public:
    long long shiftDistance(string s, string t, vector<int>& nextCost,
                            vector<int>& previousCost) {
        const int MOD = 26;
        long long ans = 0;
        // 两倍长的前缀和数组，用于解决循环问题
        long long pp[MOD * 2 + 1]{}, pn[MOD * 2 + 1]{};
        for (int i = 0; i < MOD * 2; i++) {
            pn[i + 1] = pn[i] + nextCost[i % MOD];
            pp[i + 1] = pp[i] + previousCost[i % MOD];
        }
        for (int i = 0; i < s.size(); i++) {
            int si = s[i] - 'a', ti = t[i] - 'a';
            ans +=
                min(pn[ti < si ? ti + MOD : ti] - pn[si],
                    pp[(si < ti ? si + MOD : si) + 1] - pp[ti + 1]);
        }
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(n+∣Σ∣)**

其中 n 是 s 的长度，∣Σ∣=26 是字符集合的大小

### 空间复杂度：**O(∣Σ∣)**
