[和相同的二元子数组](https://leetcode.cn/problems/binary-subarrays-with-sum/)
一模一样的一道题：[和为 K 的子数组](https://leetcode.cn/problems/subarray-sum-equals-k/)
## 解题思路

本题涉及到**对连续子数组进行求和**，所以可以用[[前缀和]]来解；同时，对于满足`prefix[r] - prefix[l] = goal`的区间`(l, r]`，`l`总是落在一个不断向右移动的连续的区间中，所以还能用[[滑动窗口]]来解

- [[前缀和]]：用[[哈希表]]记录和累加符合条件的[[前缀和]]

```cpp
class Solution {
public:
    int numSubarraysWithSum(vector<int>& nums, int goal) {
        int ans = 0, sum = 0;
        unordered_map<int, int> cnt;
        for (int& n : nums) {
	        // 统计和相同的前缀数量
            cnt[sum]++;
            // 用 sum 记录前缀和
            sum += n;
            // 累加
            ans += cnt[sum - goal];
        }
        return ans;
    }
};
```


- [[滑动窗口]]：对于这样一个处理**连续子序列**的问题，同样可以考虑用[[滑动窗口]]来解。数组右侧元素入队，破坏条件；左侧元素出队，满足条件。不过这里元素可以是 0，所以出队的元素不是单个数。而是**落在一个区间内**（即 `[left1, left2)`），该区间长度就是当前满足条件的数组数量

```cpp
class Solution {
public:
    int numSubarraysWithSum(vector<int>& nums, int goal) {
        int n = nums.size(), ans = 0;
        int right = 0, left1 = 0, left2 = 0;
        int sum1 = 0, sum2 = 0;
        while (right < n) {
            sum2 += nums[right];
            // 注意两个左指针出队条件间的区别
            while (left2 <= right && sum2 >= goal) {
                sum2 -= nums[left2++];
            }
            sum1 += nums[right];
            while (left1 <= right && sum1 > goal) {
                sum1 -= nums[left1++];
            }
            ans += left2 - left1;
            right++;
        }
        return ans;
    }
};
```

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)/O(1)**

## 总结

哈希表似乎总是要比数组慢
[[滑动窗口]]不仅能用双指针维护，还能用三指针维护；滑动窗口形式上的本质是一个队列，在解决问题方面的本质是“滑动”
