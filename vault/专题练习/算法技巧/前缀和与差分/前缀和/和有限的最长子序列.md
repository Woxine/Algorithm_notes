[和有限的最长子序列](https://leetcode.cn/problems/longest-subsequence-with-limited-sum/)
## 解题思路

- [[前缀和]] + [[二分算法]]：要求子序列的和，就用前缀和，而且虽说子序列是由一个数组删除某些元素（也可以不删除）但 **不改变剩余元素顺序** 得到的一个数组，但实际上对`[3, 2, 1]`与`[1, 2, 3]`求和**并没有区别**，于是我们总是可以先**排序**，再求前缀和；同时，序列的长度越长，和就越大，**具有单调性**，可以用二分算法对序列的长度进行二分

```cpp
class Solution {
public:
    vector<int> answerQueries(vector<int>& nums, vector<int>& queries) {
        int n = nums.size();
        // 前缀和数组
        vector<int> prefix(n + 1);
        // 排序，时间复杂度 O(nlogn)
        ranges::sort(nums);
        // 计算前缀和
        for (int i = 0; i < n; i++) {
            prefix[i + 1] = prefix[i] + nums[i];
        }
		// 对序列长度进行二分，left 及其左边的都是合法的
		// 因为 queries里的元素用一次就没用了，可以直接用来储存答案
        for (int& q : queries) {
            int left = 0, right = n + 1;
            while (left + 1 < right) {
                int mid = left + (right - left) / 2;
                (q >= prefix[mid] ? left : right) = mid;
            }
            q = left;
        }
        return queries;
    }
};
```

“优化”一下：

```cpp
class Solution {
public:
    vector<int> answerQueries(vector<int>& nums, vector<int>& queries) {
        ranges::sort(nums);
        // 原地求前缀和函数，第三个参数代表存储结果的起始迭代器
        // 当第三个参数是 nums.begin()时。代表将结果存进自身
        partial_sum(nums.begin(),nums.end(),nums.begin());
        for (int& q : queries) {
	        // 二分查找函数，查找在已排序的序列中查找第一个大于目标值的元素
	        // 该函数返回的是迭代器位置，而不是索引，于是要减去nums.begin()
	        // 如果不这么做就会返回一个类似地址的东西
            q = ranges::upper_bound(nums, q) - nums.begin();
        }
        return queries;
    }
};
```
## 复杂度分析

### 时间复杂度：**O((n + m) logn)**

其中 n 为 nums 的长度，m 为 queries 的长度。排序为 O(nlogn)，m 次二分查找为 O(mlogn)

### 空间复杂度：**O(n)/O(1)**

修改前O(n)，修改后O(1)

## 新知识点

`partial_sum` 函数用于**计算序列的部分和**，并将结果存储在**另一个序列中**。它的功能是：对于输入范围 `[first, last)`，计算每个位置 `i` 的前 `i+1` 个元素的和（即前缀和），并将结果存储到以 `result` 开始的输出范围中。此题将结果存入同一序列

`upper_bound` 函数用于在**已排序的序列**中查找第一个**大于**目标值的元素，并返回指向该元素的**迭代器**，而迭代器是一种类似**指针**的东西，想要获取该元素在序列中的**索引**而不是**地址**，就要将返回值**减去迭代器起始值**

这两个函数都是C++标准库中的函数
