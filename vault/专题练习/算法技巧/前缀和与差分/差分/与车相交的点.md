[与车相交的点](https://leetcode.cn/problems/points-that-intersect-with-cars/)
## 解题思路

假设原数组记录位置 i 是否被覆盖，一辆车能够**覆盖区间内的多个点**，可以利用[[差分]]数组**快速批量标记**，最后进行**前缀和操作复原成原数组**时，判断是否大于 0，然后累加

```cpp
class Solution {
public:
    int numberOfPoints(vector<vector<int>>& nums) {
	    // 初始化差分数组
        int d[102]{};
        for (auto& n : nums) {
            d[n[0]]++;
            d[n[1] + 1]--;
        }
        int sum = 0, ans = 0;
        for (int di : d) {
	        // 前缀和复原
            sum += di;
            ans += sum > 0;
        }
        return ans;
    }
};
```
