[航班预订统计](https://leetcode.cn/problems/corporate-flight-bookings/)
## 解题思路

[[差分]]数组统计预定数，记得修改下标

```cpp
class Solution {
public:
    vector<int> corpFlightBookings(vector<vector<int>>& bookings, int n) {
	    // 差分数组，因为航班下标从 1 开始，所以要加 1
        vector<int> ans(n + 1);
        for (auto& b : bookings) {
	        // 注意下标
            ans[b[0] - 1] += b[2];
            ans[b[1]] -= b[2];
        }
        // 原地前缀和
        for (int i = 1; i < n; i++) {
            ans[i] += ans[i - 1];
        }
        // 因为航班下标从 1 开始会导致原容器末尾有个负数，把它去掉
        ans.pop_back();
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(b)**

其中 b 是 bookings 的大小

### 空间复杂度：**O(n)**
