[拼车](https://leetcode.cn/problems/car-pooling/)
## 解题思路

[[差分]]数组例题：乘客上/下车会使乘客数在接下来的一段距离内发生变化，符合[[差分]]数组区间修改的性质：

```cpp
class Solution {
public:
    bool carPooling(vector<vector<int>>& trips, int capacity) {
	    // 初始化差分数组，下标表示距离
        int d[1001]{};
        for (auto& t : trips) {
            int num = t[0], from = t[1], to = t[2];
            // 使得区间 [from, to] 内乘客数增加
            d[from] += num;
            d[to] -= num;
        }
        int sum = 0;
        for (int& n : d) {
	        // 前缀和得到原数组
            sum += n;
            if (sum > capacity) {
                return false;
            }
        }
        return true;
    }
};
```

### 空间复杂度：**O(1)**
