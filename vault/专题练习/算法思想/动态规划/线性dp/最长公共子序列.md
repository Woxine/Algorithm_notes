[1143. 最长公共子序列 - 力扣（LeetCode）](https://leetcode.cn/problems/longest-common-subsequence/)
## 题目拆解 / 题意分析

这个问题本质上是一个“选或不选”的问题，要从两个字符串中挑一些字符组成一个公共子序列，对于每个字符都有选或不选两种选择

## 解题思路

[[动态规划]]：
状态定义：`dp[i][j]`表示 text1 中前 i 个字母，以及 text2 中前 j 个字母包含的最长公共子序列
当前操作：`text1[i]`和`text2[j]`如何选择：都选，都不选，只选一个
子问题：
- 都不选/都选：从剩下的 i - 1 和 j - 1 个字符中选
- 只选一个：从剩下的 i - 1 和 j /  i 和 j - 1 个字符中选
状态转移方程：`dp[i + 1][j + 1] = text1[i] == text2[j]? dp[i][j] + 1: max(dp[i][j + 1], dp[i + 1][j]);`

## 代码实现

```cpp
class Solution {
public:
    int longestCommonSubsequence(string text1, string text2) {
        int n = text1.size();
        int m = text2.size();
        vector dp(n + 1, vector<int>(m + 1));
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                dp[i + 1][j + 1] = text1[i] == text2[j]
                                 ? dp[i][j] + 1
                                 : max(dp[i][j + 1], dp[i + 1][j]);
            }
        }
        return dp[n][m];
    }
};
```

空间优化：注意到每次状态转移只与左，上和左上的状态有关；相比于只与两个状态有关的情况，需要添加一个临时变量存储左上的状态

```cpp
class Solution {
public:
    int longestCommonSubsequence(string s1, string s2) {
        int m = s2.size();
        vector<int> dp(m + 1);
        for (char& c : s1) {
            for (int j = 0, pre = 0; j < m; j++) {
                int temp = dp[j + 1];
                dp[j + 1] = c == s2[j] ? pre + 1 : max(dp[j + 1], dp[j]);
                pre = temp;
            }
        }
        return dp[m];
    }
};
```
