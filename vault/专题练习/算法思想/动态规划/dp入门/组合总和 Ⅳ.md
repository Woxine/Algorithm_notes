[组合总和 Ⅳ](https://leetcode.cn/problems/combination-sum-iv/)
## 题目拆解 / 题意分析

本质上是[[爬楼梯]]，相当于在说：”有 target 级台阶，有最多 200 种选择，每次最多上 1000 级，一共有多少种爬法？“这实际上就是把子问题的个数从 2 种 扩展到最多 200 种，同时要注意`dp[i-n]`中的 n 最多为 1000，小心不要越界了

## 解题思路

[[动态规划]] + 枚举：在原有基础上循环枚举所有子问题的可能

## 代码实现

```cpp
class Solution {
public:
    int combinationSum4(vector<int>& nums, int target) {
	    // 无符号整数防越界
        vector<unsigned> dp(target + 1);
        dp[0] = 1; // 定义起始状态（类似递归终点）
        for (int i = 1; i <= target; i++) {
	        // 多了一层循环用于枚举所有可能的子问题情况
            for (auto& n : nums) {
                if (n <= i) {
                    dp[i] += dp[i - n];
                }
            }
        }
        return dp[target];
    }
};
```

## 复杂度分析

### 时间复杂度：**O(target ⋅ n)**

其中 n 为 nums 的长度

### 空间复杂度：**O(target)**

## 总结 / 错误反思

这题就很能体现递归和记忆化搜索型DP**自顶向下**的本质，即从原始问题开始，递归地分解为子问题，并使用记忆化存储子问题的解
