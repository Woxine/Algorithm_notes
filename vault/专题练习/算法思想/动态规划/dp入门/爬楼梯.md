[爬楼梯](https://leetcode.cn/problems/climbing-stairs/)
## 题目拆解 / 题意分析

[[动态规划]]典中典之爬楼梯

首先定义状态，分析子问题，假设`dp[i]`表示爬到第 i 级台阶有多少种方式，我们知道，只有两条路，要么从 i - 1 级上来；要么从 i - 2 级上来。于是我们得到了子问题：爬到 i - 1 和 i - 2 级台阶有多少种方式？不断这样分解下去，我们得到了`dp[i] = dp[i - 1] + dp[i - 2]`这个状态转移方程

## 解题思路

[[动态规划]]：

- 用数组存储状态，方便复用
- 直接用变量，优化空间

## 代码实现

- dp 数组：

```cpp
class Solution {
public:
    int climbStairs(int n) {
        vector<int> f(n + 1);
        f[0] = f[1] = 1;
        for (int i = 2; i <= n; i++) {
            f[i] = f[i - 1] + f[i - 2]; // 状态转移方程
        }
        return f[n];
    }
};
```

- 变量：动态规划和核心是子问题答案复用，但是这里只涉及上一个和上上个子问题的值，所以没必要用数组都存下来，只需要每轮更新变量

```cpp
class Solution {
public:
    int climbStairs(int n) {
	    // f0 表示上上一个状态，f1 上一个状态
        int f0 = 1, f1 = 1, dp = 0;
        for (int i = 2; i <= n; i++) {
            dp = f0 + f1;
            f0 = f1;
            f1 = dp;
        }
	    // 最后 dp 赋给了 f1
        return f1;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)**

优化后O(1)
