[打家劫舍](https://leetcode.cn/problems/house-robber/)
## 题目拆解 / 题意分析

从最后一间房屋开始思考，如果选择偷这间房，那么子问题就是偷到上上间房最多赚多少；如果选择不偷这间房，那么子问题就是偷到上间房最多赚多少，以此类推

## 解题思路

- [[动态规划]] + [[递归]]：用一个 dp 数组记录偷到每间房最多赚多少，递归遍历整个数组
- 动态规划 + 枚举：遍历整个数组，维护三个变量——dp（答案），f0（上上间房）和 f1（上间房），动态规划起点是 0

## 代码实现

- 递归实现：

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(n, -1);
        // 这里是从最后一间房开始递归的，所以 i = n - 1
        auto dfs = [&](this auto&& dfs, int i) -> int {
	        // 递归终点
            if (i < 0) {
                return 0;
            }
            // 记忆化检查，避免重复计算
            if (dp[i] != -1) {
                return dp[i];
            }
            // 状态转移方程
            int ans = max(dfs(i - 2) + nums[i], dfs(i - 1));
            dp[i] = ans;
            return ans;
        };
        return dfs(n - 1);
    }
};
```

- 递推 + 空间优化：

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int f0 = 0, f1 = 0;
        for (int n : nums) {
            int dp = max(f1, f0 + n);
            f0 = f1;
            f1 = dp;
        }
        return f1;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n)**

其中 n 是 nums 的长度

### 空间复杂度：**O(n) / O(1)**
