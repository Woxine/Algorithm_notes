[使用最小花费爬楼梯](https://leetcode.cn/problems/min-cost-climbing-stairs/)
## 题目拆解 / 题意分析

这道题算[[爬楼梯]]的一种变体，`dp[i]`表示”爬到第 i 级台阶的花费“，子问题是”：爬到 i - 1 和 i - 2 级台阶的花费最小是多少“，状态转移方程就是子问题的答案加上从子问题阶数爬上来的花费最小是多少，即`dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])`

## 解题思路

[[动态规划]]：与[[爬楼梯]]类似

## 代码实现

```cpp
class Solution {
public:
    int minCostClimbingStairs(vector<int>& cost) {
        int n = cost.size();
        int f0 = 0, f1 = 0, dp = 0;
        for (int i = 2; i <= n; i++) {
            dp = min(f1 + cost[i - 1], f0 + cost[i - 2]);
            f0 = f1;
            f1 = dp;
        }
        return f1;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(n)**
### 空间复杂度：**O(1)**
