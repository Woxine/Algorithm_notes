[矩阵中移动的最大次数](https://leetcode.cn/problems/maximum-number-of-moves-in-a-grid/)
## 题目拆解 / 题意分析

寻找子问题：要找到最长的路径，那就是在下一列中找最长的，用深度优先搜索就很合适；注意第一行和最后一行的特判

## 解题思路

[[网格图]][[动态规划|dp]] + [[递归]]dfs遍历：遍历第一列的每个数作为起点，递归终点是抵达最后一列

## 代码实现

```cpp
class Solution {
public:
    int maxMoves(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();
        int ans = 0;
        auto dfs = [&](this auto&& dfs, int i, int j) -> void {
	        // 先更新答案，方便判断是否到最后一列
            ans = max(ans, j);
            if (ans == n - 1) {
                return;
            }
            // 寻找合法的下一步，递归深入，如果有的话
            for (int k = max(i - 1, 0); k <= min(m - 1, i + 1); k++) {
                if (grid[k][j + 1] > grid[i][j]) {
                    dfs(k, j + 1);
                }
            }
            // 因为矩阵中都是正整数，标记为 0 就是走过了
            // 由于只是找最长了路径，所以即使有其他的路径走到相同的格子
            // 其路径长度也不会超过之前的
            grid[i][j] = 0;
        };
        for (int i = 0; i < m; i++) {
            dfs(i, 0);
        }
        return ans;
    }
};
```
