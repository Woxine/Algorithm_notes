[网格中的最小路径代价](https://leetcode.cn/problems/minimum-path-cost-in-a-grid/)
## 题目拆解 / 题意分析

这道题在思路上和[[组合总和 Ⅳ]]有相似之处：最终问题的答案总是由上一状态加一个选择得到的，不管上一状态有多少个

## 解题思路

网格图dp：遍历矩阵，对于每个格子，遍历上一行找到代价最小的；更新答案

## 代码实现

```cpp
class Solution {
public:
    int minPathCost(vector<vector<int>>& grid, vector<vector<int>>& moveCost) {
        int m = grid.size();
        int n = grid[0].size();
        vector<vector<int>> dp(m, vector<int>(n));
        dp[0] = grid[0];
        for (int i = 1; i < m; i++) {
            for (int j = 0; j < n; j++) {
                int cost = INT_MAX;
                //  求上一行中代价最小的
                for (int k = 0; k < n; k++) {
                    cost =
                        min(cost, dp[i - 1][k] + moveCost[grid[i - 1][k]][j]);
                }
                dp[i][j] = grid[i][j] + cost;
            }
        }
        return ranges::min(dp[m - 1]);
    }
};
```
