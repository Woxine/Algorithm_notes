[下降路径最小和](https://leetcode.cn/problems/minimum-falling-path-sum/)
## 题目拆解 / 题意分析

寻找子问题：从最下面一行开始考虑，要想路径和最小，就要选左上，正上和右上中路径和最小的子路径；同时要注意最左和最右一列的特判

## 解题思路

[[网格图]][[动态规划|dp]]：一行一行遍历数组，用一个二维数组储存子路径的结果

## 代码实现

```cpp
class Solution {
public:
    int minFallingPathSum(vector<vector<int>>& matrix) {
        int m = matrix.size();
        vector<vector<int>> dp(m, vector<int>(m));
        dp[0] = matrix[0];  // 初始化
        for (int i = 1; i < m; i++) {
            for (int j = 0; j < m; j++) {
	            // 比较三条路径中最小的
                int pre_min = dp[i - 1][j];
                if (j > 0) {
                    pre_min = min(pre_min, dp[i - 1][j - 1]);
                }
                if (j < m - 1) {
                    pre_min = min(pre_min, dp[i - 1][j + 1]);
                }
                dp[i][j] = pre_min + matrix[i][j];
            }
        }
        return ranges::min(dp[m - 1]);
    }
};
```
