[不同路径](https://leetcode.cn/problems/unique-paths/)
## 题目拆解 / 题意分析

二维[[爬楼梯]]

## 解题思路

[[网格图]][[动态规划|dp]]：到当前格子的路径数量等于：到左边格子的路径数量+到上面格子的路径数量

- 状态定义：`dp(i+1, j+1)`表示从起点`[0, 0]`到格子`[i, j]`的路径总数
- 状态转移方程：`dp[i + 1][j + 1] = dp[i][j + 1] + dp[i + 1][j];`
- 边界：`f[0][j] = f[i][0] = 0`

## 代码实现

```cpp
class Solution {
public:
    int uniquePaths(int m, int n) {
        vector<vector<int>> dp(m + 1, vector<int>(n + 1));
        dp[0][1] = 1;  // 这里将dp[0][1]初始化为1是为了得到dp[1][1] = 1而不特判
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                dp[i + 1][j + 1] = dp[i][j + 1] + dp[i + 1][j];
            }
        }
        return dp[m][n];
    }
};
```
