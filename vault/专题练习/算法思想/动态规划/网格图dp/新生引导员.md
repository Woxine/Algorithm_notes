[3.新生引导员【算法赛】 - 蓝桥云课](https://www.lanqiao.cn/problems/21329/learning/?contest_id=291)
## 题目拆解 / 题意分析

本质上是一道路径问题，但是我看漏了每到达一个路径点，这个路径点会失效的条件

每一个路径点可以从它的左边，右边或下方到达

由于每一层只能向左或向右，没有回头路可以走（路径点会失效），所以同一层每个路径点的方案数相等，于是一个二维[[网格图]]问题变成了一个一维问题

## 解题思路

对于一个动态规划问题，我们首先需要定义状态，设`dp[i]`表示到达第 i 层的方案数
然后确定边界条件：到达起点`dp[1][1]`的方案为 1 种
最后写出状态转移方程：`dp[i] = (dp[i-1] * min(A[i-1], A[i]))`

- 正解：

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;
const int MOD = 998244353;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int N;
    cin >> N;

    vector<long long> A(N + 1);
    for (int i = 1; i <= N; ++i) {
        cin >> A[i];
    }
    // dp[i] 表示到达第 i 层任意开放房间的方案数
    vector<long long> dp(N + 1, 0);
    dp[1] = 1; // 起点 (1, 1)
    for (int i = 2; i <= N; ++i) {
        // 转移：dp[i] = dp[i-1] * min(A[i-1], A[i])
        // 乘法需要转为 long long 防止溢出
        dp[i] = (dp[i-1] * min(A[i-1], A[i])) % MOD;
    }
    cout << dp[N] << endl;
    return 0;
}
```

### 时间复杂度：**O(N)**

### 空间复杂度：**O(N)**
