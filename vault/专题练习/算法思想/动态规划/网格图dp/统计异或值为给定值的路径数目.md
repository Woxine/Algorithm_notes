[统计异或值为给定值的路径数目](https://leetcode.cn/problems/count-paths-with-the-given-xor-value/)
## 题目拆解 / 题意分析

这道题的麻烦之处就在于我们在到达一个格子时，不知道具体是怎么走过来的，只知道是从上面或左边来，这就导致了我们并不知道之前的异或和是多少，以及走这个格子具体会带来什么样的变化；如果我们只记录异或和为 k 的路径数，那么当我们在某个格子时，我们无法知道从左边或上边来的路径中，哪些异或和经过当前格子后会变成 k，因为当前格子的值会改变异或和

因为异或运算的这一特性，我们不得不单独开一个维度储存所有可能的异或结果

## 解题思路

[[网格图]][[动态规划|dp]]：与[[最小路径和]]相似，但是要处理异或和

## 代码实现

```cpp
class Solution {
    const int MOD = 1000000007;

public:
    int countPathsWithXorValue(vector<vector<int>>& grid, int k) {
        int m = grid.size();
        int n = grid[0].size();
        int mx = 0;
        // 用于计算上限
        for (auto& row : grid) {
            mx = max(mx, ranges::max(row));
        }
        // 路径上的异或和不会超过 u - 1
        int u = 1 << bit_width((unsigned)mx);
        // 如果 k 超过了 u, 就不可能得到
        if (k >= u) {
            return 0;
        }
        vector dp(m + 1, vector(n + 1, vector<int>(u)));
        dp[0][1][0] = 1;
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
	            // 记录每一个可能的异或结果
                for (int x = 0; x < u; x++) {
                    int cur = grid[i][j];
                    // 异或运算是可逆的
                    // 如果 pre_xor ^ cur = x
                    // 那么 pre_xor = x ^ cur
                    dp[i + 1][j + 1][x] =
                        (dp[i][j + 1][x ^ cur] 
                       + dp[i + 1][j][x ^ cur]) % MOD;
                }
            }
        }
        return dp[m][n][k];
    }
};
```
