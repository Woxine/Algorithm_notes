[三角形最小路径和](https://leetcode.cn/problems/triangle/)
## 题目拆解 / 题意分析

如果只是贪心的选择更小的下层标点，不一定能够得到总体最小的和，这道题其实自底向上考虑会更好。题目相当于是：从最底下那一层任意一个数作为起点，一直向上到达顶点的最小路径和是多少

- 寻找子问题：到顶点的路径和最小，那么到下层相邻标点的路径和最小
- 定义状态：设`dp[i][j]`表示到位置`(i, j)`时的最小路径和
- 状态转移方程：`dp[i][j] = min(dp[i + 1][j], dp[i + 1][j + 1]) + cur;`

## 代码实现

```cpp
class Solution {
public:
    int minimumTotal(vector<vector<int>>& triangle) {
        int high = triangle.size();
        vector<vector<int>> dp(high, vector<int>(high));
        dp[high - 1] = triangle[high - 1];
        for (int i = high - 2; i >= 0; i--) {
            for (int j = 0; j <= i; j++) {
                int cur = triangle[i][j];
                dp[i][j] = min(dp[i + 1][j], dp[i + 1][j + 1]) + cur;
            }
        }
        return dp[0][0];
    }
};
```
