[分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/)
## 题目拆解 / 题意分析

其实就是在求能不能从数组中找到一组数，其总和为 sum / 2

## 解题思路

[[动态规划]]：遍历数组，考虑每个数选或不选，如果选是什么情况，不选又是什么情况
状态定义：`dp[i][j]`表示选完前 i 个数，能不能得到 j
边界状态：`dp[0][0] = true`表示什么都没选得到 0
状态转移方程：`dp[i + 1][j] = (j >= cur && dp[i][j - cur]) || dp[i][j]`：如果选当前数，那就看之前的和加上当前的能不能得到；如果不选，直接继承之前的

## 代码实现

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int n = nums.size();
        int sum = reduce(nums.begin(), nums.end(), 0);
        if (sum % 2) {
            return false;
        }
        sum /= 2;
        vector dp(n + 1, vector<bool>(sum + 1));
        dp[0][0] = true;  // 空集也算一种
        for (int i = 0; i < n; i++) {
            int cur = nums[i];
            for (int j = 0; j <= sum; j++) {
                dp[i + 1][j] = (j >= cur && dp[i][j - cur]) || dp[i][j];
            }
        }
        return dp[n][sum];
    }
};
```

空间优化：

```cpp
class Solution {
public:
    bool canPartition(vector<int>& nums) {
        int sum = reduce(nums.begin(), nums.end(), 0);
        if (sum % 2) {
            return false;
        }
        sum /= 2;
        vector<int> dp(sum + 1);
        dp[0] = true;
        int remain = 0;
        for (int n : nums) {
            remain = min(remain + n, sum);
            for (int j = remain; j >= n; j--) {
                dp[j] |= dp[j - n];
            }
        }
        return dp[sum];
    }
};
```
