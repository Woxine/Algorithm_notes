[和为目标值的最长子序列的长度](https://leetcode.cn/problems/length-of-the-longest-subsequence-that-sums-to-target/)
## 题目拆解 / 题意分析

## 解题思路

[[动态规划]]：

- 遍历数组，判断当前数选还是不选；选的话和为多少，不选的话和为多少
- 状态定义：`dp[i][j]`表示前 i 个数中，总和为 j 的最长序列长度
- 状态转移方程：`dp[i + 1][j] = max(dp[i][j], dp[i][j - nums[i]] + 1)`

## 代码实现

```cpp
class Solution {
public:
    int lengthOfLongestSubsequence(vector<int>& nums, int target) {
        int n = nums.size();
        vector dp(n + 1, vector<int>(target + 1, -1000));
        dp[0][0] = 0;  // 前0个数中得到的和为0的序列，但是这样的情况是不合法的
        for (int i = 0; i < n; i++) {
            for (int j = 0; j <= target; j++) {
                if (nums[i] > j) {
                    dp[i + 1][j] = dp[i][j];
                } else {
                    dp[i + 1][j] = max(dp[i][j], dp[i][j - nums[i]] + 1);
                }
            }
        }
        return dp[n][target] > 0 ? dp[n][target] : -1;
    }
};
```

空间优化：

```cpp
class Solution {
public:
    int lengthOfLongestSubsequence(vector<int>& nums, int target) {
        vector dp(target + 1, INT_MIN);
        dp[0] = 0;
        for (int n : nums) {
            for (int j = target; j >= n; j--) {
                dp[j] = max(dp[j], dp[j - n] + 1);
            }
        }
        return dp[target] > 0 ? dp[target] : -1;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n·target)**

### 空间复杂度：**O(n·target)/O(target)**
