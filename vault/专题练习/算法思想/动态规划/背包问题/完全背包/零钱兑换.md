[零钱兑换](https://leetcode.cn/problems/coin-change/)
## 题目拆解 / 题意分析

跟[[和为目标值的最长子序列的长度]]反着来的，区别在于状态转移方程

## 解题思路

[[动态规划]]：

- 状态定义：`dp[i][j]`表示从前 i 种硬币选，得到总和 j 的最少硬币数
- 状态转移方程：`dp[i + 1][j] = min(dp[i][j], dp[i + 1][j - c] + 1)`

如果不选第 i+1 种硬币，子问题就是从前 i 种硬币种选，得到 j ；如果选，子问题就是从前 i+1 种硬币中选，得到 j - c（c 是当前硬币面额）

## 代码实现

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        int n = coins.size(); // 硬币种类
        vector dp(n + 1, vector<int>(amount + 1, INT_MAX / 2));
        dp[0][0] = 0;  // 0个硬币总和为0，并不合法
        for (int i = 0; i < n; i++) {
            int c = coins[i];
            for (int j = 0; j <= amount; j++) {
                if (c > j) {
                    dp[i + 1][j] = dp[i][j];
                } else {
	                // 选的话从dp[i + 1][j - c]来，而不是dp[i][j - c]
	                // 代表选了还能选
                    dp[i + 1][j] = min(dp[i][j], dp[i + 1][j - c] + 1);
                }
            }
        }
        int ans = dp[n][amount];
        return ans < INT_MAX / 2 ? ans : -1;
    }
};
```

空间优化：

```cpp
class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, INT_MAX / 2);
        dp[0] = 0;
        for (int c : coins) {
            for (int j = c; j <= amount; j++) {
                dp[j] = min(dp[j], dp[j - c] + 1);
            }
        }
        int ans = dp[amount];
        return ans < INT_MAX / 2 ? ans : -1;
    }
};
```
