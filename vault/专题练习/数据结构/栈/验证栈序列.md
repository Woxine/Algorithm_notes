[验证栈序列](https://leetcode.cn/problems/validate-stack-sequences/)
## 解题思路

[[栈]]基础，纯模拟：优先入栈，能出栈就出栈

```cpp
class Solution {
public:
    bool validateStackSequences(vector<int>& pushed, vector<int>& popped) {
        vector<int> st;
        for (int i = 0, j = 0; i < pushed.size(); i++) {
            st.emplace_back(pushed[i]);
            while (!st.empty() && st.back() == popped[j]) {
                st.pop_back();
                j++;
            }
        }
        // 因为 pushed 中所有元素一定都会入一次栈
        // 所以如果栈为空，说明全部出栈，返回 true，否则返回 false
        return st.empty();
    }
};
```

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)**

## 新知识点

```cpp
	while (!st.empty() && st.back() == popped[j]) {
        st.pop_back();
        j++;
    }
```

表达式`p && q`中会先判断 `p`，所以如果反过来写成：

```cpp
	while (st.back() == popped[j] && !st.empty()) {
        st.pop_back();
        j++;
    }
```

就不对，因为如果 `st` 为空,`st.back()`就不知道返回什么了（因为就不存在“最后一个值”，这是个未定义行为）
