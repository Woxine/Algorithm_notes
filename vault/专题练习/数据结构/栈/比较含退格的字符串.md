[比较含退格的字符串](https://leetcode.cn/problems/backspace-string-compare/)
## 解题思路

- [[栈]]基础：纯模拟，是数字就入栈；不是数字就出栈

```cpp
class Solution {
public:
    bool backspaceCompare(string s, string t) {
        return compare(s) == compare(t);
    }

    string compare(string str) {
        string ans;
        for (char& c : str) {
            if (c != '#') {
	            // 相当于 ans.push_back(c)
                ans += c;
            } else if (!ans.empty()) {
                ans.pop_back();
            }
        }
        return ans;
    }
};
```

### 空间复杂度：**O(1)**
