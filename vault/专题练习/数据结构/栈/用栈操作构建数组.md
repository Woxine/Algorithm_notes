[用栈操作构建数组](https://leetcode.cn/problems/build-an-array-with-stack-operations/)
## 解题思路

作为一道[[栈]]基础入门题，有助于理解[[栈]]“**先进后出**”的特点
这道题就是说有的数不需要入栈，那么遍历的时候入栈再出栈就行

```cpp
class Solution {
public:
    vector<string> buildArray(vector<int>& target, int n) {
        vector<string> ans;
        int pre = 0;
        for (int& num : target) {
	        // num - pre - 1 表示当前数与上一个数之间有多少数不需要入栈
            for (int i = 0; i < num - pre - 1; i++) {
                ans.emplace_back("Push");
                ans.emplace_back("Pop");
            }
            // 当前数入栈
            ans.emplace_back("Push");
            pre = num;
        }
        return ans;
    }
};
```

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)**
