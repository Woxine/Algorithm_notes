[棒球比赛](https://leetcode.cn/problems/baseball-game/)
## 解题思路

[[栈]]基础：纯模拟

```cpp
class Solution {
public:
    int calPoints(vector<string>& operations) {
        vector<int> stack;
        for (auto& c : operations) {
	        // switch 只接受 int 或 char
		    // 获取 string 的第一个元素就是 char 了
            switch (c[0]) {
            case 'C':
                stack.pop_back();
                break;
            case 'D':
	            // stack.back() 就相当与查看栈顶了
                stack.emplace_back(stack.back() * 2);
                break;
            case '+':
	            // 因为是用 vector 实现的，所以能操作栈顶以外的元素
                stack.emplace_back(stack.back() + stack[stack.size() - 2]);
                break;
            default:
	            // stoi() 能将 string 转成 int
                stack.emplace_back(stoi(c));
            }
        }
        // 求和函数
        return reduce(stack.begin(), stack.end());
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)**

## 新知识点

`switch` 只接受 `int` 或 `char`

`stoi()` 能将 `string` 转成 `int`
