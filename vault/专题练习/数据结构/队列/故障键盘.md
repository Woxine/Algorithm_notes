[故障键盘](https://leetcode.cn/problems/faulty-keyboard/)
## 解题思路

- 暴力模拟 O($n^2$)：每次遇到 i 就直接反转字符串

```cpp
class Solution {
public:
    string finalString(string s) {
        string ans;
        for(auto& c : s){
            if(c == 'i'){
                reverse(ans.begin(),ans.end());
            }else{
                ans += c;
            }
        }
        return ans;
    }
};
```

- 双端[[队列]] O(n)：每次反转都会带来 O(n) 的时间，那有没有什么办法能够用 O(1) 的时间**模拟**反转这个操作呢？分析题目，我们**总是在为字符串添加字符**，反转带来的唯一变化就是添加字符的方向和位置，所以我们需要一个能在首尾进行增删操作的[[队列]]，用一个布尔变量记录方向

```cpp
class Solution {
public:
    string finalString(string s) {
        deque<char> q;
	    string ans;
	    // 记录方向
        bool rev = false;
        for(auto& c : s){
            if(c == 'i'){
                rev = !rev;
            }else{
	            // 反转了就往队首加，否则往队尾加
                rev ? q.push_front(c) : q.push_back(c); 
            }
        }
        // 反转了就倒过来
        if(rev){
	        ans = string(q.rbegin(),q.rend());
        }else{
	        ans = string(q.begin(),q.end());
        }
        return ans;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)**

## 新知识点

`ans = string(q.rbegin(),q.rend());`涉及**反向迭代器**，就是从后往前遍历

## 总结

这种思路的本质是：**抓住操作的 “逻辑本质”，用更轻量的方式模拟复杂操作**，这在处理 “频繁反转”“频繁插入删除” 等问题时很常用
