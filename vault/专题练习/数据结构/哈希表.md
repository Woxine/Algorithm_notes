## 什么是哈希表？

哈希表是一种**键值对（Key-Value）存储结构**，通过哈希函数将 Key 转换为数组索引，直接定位 Value 的存储位置，实现近乎 O (1) 的平均时间复杂度。C++中的哈希表（通常通过 `std::unordered_map` 实现）与 Python 中的字典（`dict`）在本质上是**同一种数据结构**，均基于**哈希表（Hash Table）** 实现。

## 它有什么用？

哈希表除了有常见的增删改查之外，我认为它最重要的功能/特性是反映了键值对之间的一一对应关系，因为**哈希表（Hash Table）** 中不存在相同的键。由此它应当有以下功能：

- 快速查找：我们能够以O(1)复杂度快速找到我们想要的特殊值
- 去重：因为哈希表中没有相同的键/**统计元素的出现次数**
- 计数：记录统一种类型的值的数量

## 补充

`unordered_set` 和 `unordered_map` 是 C++ 标准库中两种常用的哈希表容器，它们都基于哈希表实现，提供平均 O (1) 时间复杂度的查找、插入和删除操作，但它们的用途和存储结构有显著区别：

### 核心区别

1. **存储内容不同**
    - `unordered_set` 是**无序集合**，仅存储**单一值（value）**，且元素不可重复
    - `unordered_map` 是**无序映射**，存储**键值对（key-value）**，键（key）不可重复，值（value）可重复
2. **用途不同**
    - `unordered_set` 适合用于**快速判断某个值是否存在**（去重 + 查询场景）
    - `unordered_map` 适合用于**通过键快速查找对应的值**（键值关联场景）
3. **接口差异**
    - `unordered_set` 的插入是 `insert(value)`，查找是 `find(value)`
    - `unordered_map` 的插入是 `insert({key, value})` 或 `map[key] = value`，查找是 `find(key)`
### 总结选择建议

- 当需要**去重和快速存在性判断**时，用 `unordered_set`
- 当需要**通过唯一键关联并查询对应值**时，用 `unordered_map`
