[最小未被占据椅子的编号](https://leetcode.cn/problems/the-number-of-the-smallest-unoccupied-chair/)
## 解题思路

[[堆]]（优先队列）+ [[哈希表]] + 问题拆分 + 模拟：这道题的每个朋友对象会有两种行为，到达和离开；我们需要按时序排列他们的行为，然后用小根堆维护空出来的座位，用哈希表记录每个座位是谁在坐，要注意离开操作要先于到达操作处理

```cpp
class Solution {
public:
    int smallestChair(vector<vector<int>>& times, int targetFriend) {
        int n = times.size();
        // 由于不用计数，而且位置固定，只是存储人员信息
        // 可以用 pair 代替 hashmap
        vector<pair<int, int>> arrival;
        vector<pair<int, int>> leaving;
        // 初始化并按时序记录到达/离开操作,方便接下来的遍历操作
        for (int i = 0; i < n; i++) {
            arrival.emplace_back(times[i][0], i);
            leaving.emplace_back(times[i][1], i);
        }
        ranges::sort(arrival);
        ranges::sort(leaving);
        // 创建小根堆维护空座位
        priority_queue<int, vector<int>, greater<>> emptySet;
        for (int i = 0; i < n; ++i) {
            emptySet.push(i);
        }
        // 用哈希表记录座位的人员占据情况
        unordered_map<int, int> seats;
        int j = 0;
        // 结构化绑定
        for (auto&& [time, friends] : arrival) {
            // 优先处理离开操作，把位置空出来
            while (j < n && leaving[j].first <= time) {
                emptySet.push(seats[leaving[j++].second]);
            }
            // 然后处理到达操作
            int seat = emptySet.top();
            seats[friends] = seat;
            emptySet.pop();
            // 找到直接返回
            if (targetFriend == friends) {
                return seat;
            }
        }
        return -1;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(nlogn)**

### 空间复杂度：**O(n)**

两个数组、最小堆、哈希表的空间开销均为 O(n)

## 总结

行为多，参数多，状态多，变量多……我一遇到这种题就搞不来了。做题不能老想着一步到位，要一步一步分析，把复杂问题拆解成简单问题。

这道题最后要返回**特定编号的朋友**占据的**椅子编号**，所以要用类似字典（哈希表）的东西存储
还需要一个小根堆来维护空出来的座位，支持**快速查找编号最小**的椅子
然后就是离开和到达操作，分别对应入队和出队
最后要按时序处理朋友们的操作，所以存储对应朋友的操作后还要排序
