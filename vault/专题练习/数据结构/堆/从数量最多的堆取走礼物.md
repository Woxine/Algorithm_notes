[从数量最多的堆取走礼物](https://leetcode.cn/problems/take-gifts-from-the-richest-pile/)
## 解题思路

优先队列（[[堆]]）纯模拟：用[[贪心算法]]总是取出数量最多的那一堆，然后开方

```cpp
class Solution {
public:
    long long pickGifts(vector<int>& gifts, int k) {
        priority_queue<int> pq;
        // 创建堆
        for (int g : gifts) {
            pq.push(g);
        }
        while (k--) {
            int top = pq.top();
            pq.pop();
            pq.push((int)sqrt(top));
        }
        long long ans = 0;
        // 由于优先队列是一种容器适配器，并不支持 begin(), end() 这样的迭代器
        // 所以只能用这种方式累加
        while (pq.size()) {
            ans += pq.top();
            pq.pop();
        }
        return ans;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(klogn)**

其中 n 为 gifts 的长度，每次维护堆序需要 O(logn) 的时间，一共有 k 次

### 空间复杂度：**O(n)**
