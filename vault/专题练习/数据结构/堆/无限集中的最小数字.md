[无限集中的最小数字](https://leetcode.cn/problems/smallest-number-in-infinite-set/)
## 解题思路

有序集合（set）：总是 **移除** 并返回该无限集中的 **最小** 整数，很容易想到小根堆；但是[[堆]]并没有提供去重功能，要么额外开一个哈希表来计数，要么就直接用有序集合（set），它既能去重，又能排序。

根据题意，要么添加**任意**的正整数（如果它已经被移除），要么删除**最小**的正整数；在初始状态下，类中包含**所有正整数**，所以我们在移除第一个数（1）之前所有加入操作都无效。进一步的，我们不妨假设程序运行到某一状态时，存在正整数 `remain`，区间`[remain, +∞]`的加入操作无效（这个区间内的数还没有被移除过）；接着我们用一个 set 来维护**小于**`remain`的所有正整数，表示它们被移除，只有当我们想添加的数**小于**`remain`时，将它加入 set

如果要删除最小的正整数，那么当 set 为空时，删除 remain 并将 remain 的值增加 1；否则我们删除 set 中最小的正整数

如果要添加一个正整数，如果它大于等于 remain，则不进行任何操作，否则将其加入 s 中

```cpp
class SmallestInfiniteSet {
    int remain = 1;
    set<int> s;

public:
    SmallestInfiniteSet() {}

    int popSmallest() {
        if (s.empty()) {
            int top = remain++;
            return top;
        }
        int top = *s.begin();
        s.erase(s.begin());
        return top;
    }

    void addBack(int num) {
        if (num < remain) {
            s.insert(num);
        }
    }
};

/**
 * Your SmallestInfiniteSet object will be instantiated and called as such:
 * SmallestInfiniteSet* obj = new SmallestInfiniteSet();
 * int param_1 = obj->popSmallest();
 * obj->addBack(num);
 */
```

### 空间复杂度：**O(n)**

## 新知识点

C++ 标准库中的 `<set>` 是一个关联容器，它存储了一组唯一的元素，并按照一定的顺序进行排序

`<set>` 提供了高效的元素查找、插入和删除操作。它是基于红黑树实现的，因此具有对数时间复杂度的查找、插入和删除性能

`<set>` 容器中存储的元素类型必须满足以下条件：

- 元素类型必须可以比较大小。
- 元素类型必须可以被复制和赋值。

`<set>` 是 C++ 标准库中一个非常有用的容器，特别适合需要快速查找、插入和删除操作的场景
