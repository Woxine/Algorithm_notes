[座位预约管理系统](https://leetcode.cn/problems/seat-reservation-manager/)
## 解题思路

- 堆（优先队列）：直接模拟，这个方法的时空复杂度都在 O(n)，每次修改操作都在 O(logn)

```cpp
class SeatManager {
    priority_queue<int, vector<int>, greater<>> min_heap;

public:
    SeatManager(int n) {
        for (int i = 1; i <= n; i++) {
            min_heap.push(i);
        }
    }

    int reserve() {
        int seat = min_heap.top();
        min_heap.pop();
        return seat;
    }

    void unreserve(int seatNumber) { min_heap.push(seatNumber); }
};
```

- 优化：实际上这道题跟[[无限集中的最小数字]]很像，可以将初始化优化为 O(1)，然后维护取消预约的座位

```cpp
class SeatManager {
    int remain = 1;
    priority_queue<int, vector<int>, greater<>> min_heap;

public:
    SeatManager(int n) {}

    int reserve() {
        if (min_heap.empty()) {
            return remain++;
        } else {
            int top = min_heap.top();
            min_heap.pop();
            return top;
        }
    }

    void unreserve(int seatNumber) { min_heap.push(seatNumber); }
};
```
