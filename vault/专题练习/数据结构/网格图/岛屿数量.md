[岛屿数量](https://leetcode.cn/problems/number-of-islands/)
## 题目拆解 / 题意分析

很经典的[[网格图]] DFS，网格图递归和二叉树递归没有本质上的区别，只是两条岔路变成四条岔路了

## 解题思路

[[递归]] + 网格图 dfs：循环嵌套遍历二维数组，每当碰到陆地，说明到达了一个新的岛屿；然后深度优先搜索寻找所有连在一起的陆地，具体来说就是每到一片陆地，先往一个方向走到头，然后再回来走另一方向，一路走到头；最后就能够递归地遍历每一片陆地的上下左右四个方向

## 代码实现

```cpp
class Solution {
public:
    int numIslands(vector<vector<char>>& grid) {
        int ans = 0;
        int row = grid.size(), column = grid[0].size();
        auto dfs = [&](this auto&& dfs, int i, int j) -> void {
	        // 递归边界：出界或不是陆地
            if (i < 0 || i >= row || j < 0 || j >= column 
			          || grid[i][j] != '1') {
                return;
            }
            // 将遍历过的陆地标记（清零）
            grid[i][j] = '0';
            dfs(i, j - 1); // 左
            dfs(i, j + 1); // 右
            dfs(i - 1, j); // 上
            dfs(i + 1, j); // 下
        };

        for (int i = 0; i < row; i++) {
            for (int j = 0; j < column; j++) {
                if (grid[i][j] == '1') {
                    dfs(i, j);
                    ans++;
                }
            }
        }
        return ans;
    }
};
```
