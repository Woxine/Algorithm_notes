[边界着色](https://leetcode.cn/problems/coloring-a-border/)
## 题目拆解 / 题意分析

[[岛屿数量]]的变种，区别是要找到“岛屿的边界”，但是判断是否为边界需要借助与边界相邻的地块，这就导致在一次递归中不好操作，比较麻烦

## 解题思路

[[网格图]]dfs + [[递归]]：想要在一次递归中完成边界判断，标记和染色有些困难，于是我们考虑将染色的步骤与搜索的步骤分开来；先遍历矩阵，找出边界，最后再染色

## 代码实现

```cpp
class Solution {
    static constexpr int DIRS[4][2] = {
        {0, -1}, {0, 1}, {-1, 0}, {1, 0}}; // 左右上下
public:
    vector<vector<int>> colorBorder(vector<vector<int>>& grid, 
					    int row, int col, int color) {
        int m = grid.size();
        int n = grid[0].size();
        int start = grid[row][col];
        // 因为最后要返回修改后的 grid，不能再像以前那样通过特殊值标记是否访问了
        // 单独同一个 visited 布尔数组标记
        vector<vector<bool>> visited(m, vector<bool>(n, false));
        vector<pair<int, int>> borders;  // 记录边界位置
        auto dfs = [&](this auto&& dfs, int i, int j) -> void {
            visited[i][j] = true;
            bool isBorder = false;
            for (auto [dx, dy] : DIRS) {
                int x = i + dx, y = j + dy;
                // 碰到边界标记
                if (x < 0 || x >= m || y < 0 || y >= n || 
	                grid[x][y] != start) {
                    isBorder = true;
                } else if (!visited[x][y]) {
                    dfs(x, y);
                }
            }
            // 新增边界位置
            if (isBorder) {
                borders.emplace_back(i, j);
            }
        };
        dfs(row, col);
        // 更新边界颜色
        for (auto [i, j] : borders) {
            grid[i][j] = color;
        }
        return grid;
    }
};
```
