[1475. 商品折扣后的最终价格](https://leetcode.cn/problems/final-prices-with-a-special-discount-in-a-shop/)
## 题目拆解 / 题意分析

## 解题思路

[[单调栈]]：维护一个单调递减栈，如果栈顶元素大于当前元素，弹栈，这样就能找到最近的比当前元素小的元素了

## 代码实现

- 从右往左遍历，栈中记录折扣值：

```cpp
class Solution {
public:
    vector<int> finalPrices(vector<int>& prices) {
        int n = prices.size();
        vector<int> ans(n);
        stack<int> st;
        st.push(0);  // 哨兵，如果没有更便宜的就没有折扣
        for (int i = n - 1; i >= 0; i--) {
            int p = prices[i];
            while (!st.empty() && p < st.top()) {
                st.pop();
            }
            ans[i] = p - st.top();
            st.push(p);
        }
        return ans;
    }
};
```

- 从左往右遍历，栈中记录还没有找到折扣的值的下标：

```cpp
class Solution {
public:
    vector<int> finalPrices(vector<int>& prices) {
        stack<int> st;
        for (int i = 0; i < prices.size(); i++) {
            int p = prices[i];
            while (!st.empty() && p <= prices[st.top()]) {
                prices[st.top()] -= p;
                st.pop();
            }
            st.push(i);
        }
        return prices;
    }
};
```
## 复杂度分析

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)**

## 总结 / 错误反思

从左往右遍历时，栈更像是一个“todolist”，记录了还没有找到折扣的值，一旦找到就不需要再考虑从，所以从栈中弹出；

从右往左遍历时，栈维护的是可以作为折扣的值，如果找到更小的，那更大就没有用了，所以从栈中弹出
