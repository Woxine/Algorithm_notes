- [739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)
## 题目拆解 / 题意分析

题目要求“下一个更高温度出现在几天后”，所以需要统计每个数右侧第一个严格大于该数的下标，所以我们应该从右侧开始遍历

## 解题思路

[[单调栈]]：从又开始遍历元素，如果栈顶元素比当前元素小，弹栈；如果栈不为空说明栈顶元素比当前元素大，记录下标差值

## 代码实现

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> ans(n);
        stack<int> st;
        for (int i = n - 1; i >= 0; i--) {
            int x = temperatures[i];
            while (!st.empty() && temperatures[st.top()] <= x) {
                st.pop();
            }
            if(!st.empty()){
                ans[i] = st.top() - i;
            }
            st.push(i);
        }
        return ans;
    }
};
```
