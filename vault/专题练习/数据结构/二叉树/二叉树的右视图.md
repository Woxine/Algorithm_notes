[二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/)
## 题目拆解 / 题意分析

右视图就是左边会被遮起来呗，而且答案数组的长度就会等于[[二叉树]]的深度（这很关键）

## 解题思路

**dfs + [[递归]]**：既然是右视图就需要先找到最深的右子树，所以先 dfs 遍历右节点；同时用一个变量记录深度，如果第一次到达这个深度才记录数据

## 代码实现

```cpp
class Solution {
public:
    vector<int> rightSideView(TreeNode* root) {
        vector<int> ans;
        auto dfs = [&](this auto&& dfs, TreeNode* node, int depth) -> void {
            if (!node) {
                return;
            }
            // 第一次到达这个深度
            if (depth == ans.size()) {
                ans.emplace_back(node->val);
            }
            dfs(node->right, depth + 1);
            dfs(node->left, depth + 1);
        };
        dfs(root, 0);
        return ans;
    }
};
```
