[二叉搜索树节点最小距离](https://leetcode.cn/problems/minimum-distance-between-bst-nodes/)
## 题目拆解 / 题意分析

如果要求**最大差值**，用有序序列的首尾相减即可；而要求**最小差值**，只能一对一对比较序列中的数。二叉搜索树的一个重要性质就是，**中序遍历**得到的序列是有序的，我们可以计算中序遍历中的相邻两数的差值，取最小值

## 解题思路

[[递归]] + dfs + [[二叉树]]中序遍历

## 代码实现

```cpp
class Solution {
public:
    int getMinimumDifference(TreeNode* root) {
        int ans = 100001, pre = -100001;
        auto dfs = [&](this auto&& dfs, TreeNode* node) -> void {
            if (!node) {
                return;
            }
            dfs(node->left);
            ans = min(ans, node->val - pre);
            pre = node->val;
            dfs(node->right);
        };
        dfs(root);
        return ans;
    }
};
```
