[二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)
## 题目拆解 / 题意分析

就是要在[[递归]]过程中记录深度，边界条件就是到达叶子节点，子问题就是找到左右子树中更大的深度，有两种解法

## 解题思路

- 自顶向下：从根节点开始不断向下更新深度，并且将更大的深度存到 ans 里
- 自底向上：遇到叶节点触发 “归”，每向上一层便增加深度，最终深度就是子树深度加 1

## 代码实现

- 自顶向下：
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        int ans = 0;
        auto dfs = [&](this auto&& dfs, TreeNode* node, int depth) -> void {
            if (!node) {
                return;
            }
            depth++;
            ans = max(ans, depth);
            dfs(node->left, depth);
            dfs(node->right, depth);
        };
        dfs(root, 0);
        return ans;
    }
};
```
- 自底向上：
```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) {
            return 0;
        }
        int left_depth = maxDepth(root->left);
        int right_depth = maxDepth(root->right);
        return max(left_depth, right_depth) + 1;
    }
};
```
