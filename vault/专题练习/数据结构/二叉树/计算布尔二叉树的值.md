[计算布尔二叉树的值](https://leetcode.cn/problems/evaluate-boolean-binary-tree/)
## 题目拆解 / 题意分析

边界条件就是碰到叶子节点，满[[二叉树]]非叶子节点都有两片叶子，所以很好判断

## 解题思路

[[递归]] + dfs + 模拟：按照题意模拟

## 代码实现

```cpp
class Solution {
public:
    bool evaluateTree(TreeNode* root) {
        if(!root->right){
            return root->val;
        }
        if(root->val == 2){
            return evaluateTree(root->left) || evaluateTree(root->right);
        }else{
            return evaluateTree(root->left) && evaluateTree(root->right);
        }
    }
};
```
