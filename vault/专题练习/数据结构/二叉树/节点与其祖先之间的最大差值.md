[节点与其祖先之间的最大差值](https://leetcode.cn/problems/maximum-difference-between-node-and-ancestor/)
## 题目拆解 / 题意分析

这道题看似对节点之间的辈分关系做了限制，但是由于求的是绝对值，所以最后找的还是最大值和最小值

## 解题思路

递归 + dfs：深度优先搜索遍历整条路经，然后找到这条路上的最值，更新答案

## 代码实现

```cpp
class Solution {
public:
    int maxAncestorDiff(TreeNode* root) {
        int ans = -1;
        auto dfs = [&](this auto&& dfs, TreeNode* node, int mn,
                       int mx) -> void {
            if (!node) {
                ans = max(ans, mx - mn);
                return;
            }
            mn = min(mn, node->val);
            mx = max(mx, node->val);
            dfs(node->left, mn, mx);
            dfs(node->right, mn, mx);
        };
        dfs(root, INT_MAX, 0);
        return ans;
    }
};
```
