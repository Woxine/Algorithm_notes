[祖父节点值为偶数的节点和](https://leetcode.cn/problems/sum-of-nodes-with-even-valued-grandparent/)
## 题目拆解 / 题意分析

关键点有两个：1. 找到祖父节点 2. 判断奇偶性

## 解题思路

[[递归]] + dfs + [[位运算]]：[[递归]]地遍历[[二叉树]]中的节点，判断是否有祖父节点，以及祖父节点是否是偶数。像这样对一系列数的**二元性质**（奇偶性）作判断时，可以借助[[位运算]]，用一段掩码记录这一串数字的奇偶性

## 代码实现

```cpp
class Solution {
public:
    int sumEvenGrandparent(TreeNode* root) {
        int ans = 0;
        auto dfs = 
        [&](this auto&& dfs, TreeNode* node, int mask, int depth) -> void {
            if (!node) {
                return;
            }
            // 掩码中存储的是祖父节点的奇偶性
            // 每向下一层，祖父之前的节点就要被舍弃了
            mask >>= 1;
            if (depth > 1 && (mask & 1) == 0) {
                ans += node->val;
            }
            mask |= (node->val & 1) << 2;
            dfs(node->left, mask, depth + 1);
            dfs(node->right, mask, depth + 1);
        };
        dfs(root, 0, 0);
        return ans;
    }
};
```
