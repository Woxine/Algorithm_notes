[叶子相似的树](https://leetcode.cn/problems/leaf-similar-trees/)
## 题目拆解 / 题意分析

题目要返回一个布尔值，反映两个**叶值序列**是否相同，那么如何得到这个序列？这里选择用[[二叉树]]的先序遍历每一个节点，然后**判断它是否为叶子**（即**既没有左孩子也没有右孩子**），将这个叶子存入序列，因为有两棵树，所以需要两个容器

## 解题思路

1. **收集叶子值序列**：用[[递归]]遍历[[二叉树]]，当遇到**左右子节点都为空**的叶子节点时，记录其值
2. **比较序列**：分别收集两棵树的叶子值序列，若两个序列完全一致，则返回`true`，否则返回`false`

## 代码实现

```cpp
class Solution {
public:
    bool leafSimilar(TreeNode* root1, TreeNode* root2) {
        vector<int> val1, val2;
        recursion(root1, val1);
        recursion(root2, val2);
        return val1 == val2;
    }

    void recursion(TreeNode* root, vector<int>& val) {
        if (!root) {
            return;
        }
        if (root->left == nullptr && root->right == nullptr) {
            val.emplace_back(root->val);
        }
        recursion(root->left, val);
        recursion(root->right, val);
    }
};
```

内置lambda函数简化：

```cpp
class Solution {
    vector<int> leafValues(TreeNode* root) {
        vector<int> res;
        auto dfs = [&](this auto&& dfs, TreeNode* node) -> void {
            if (node == nullptr) { // 空节点
                return;
            }
            if (node->left == nullptr && node->right == nullptr) { // 叶子
                res.push_back(node->val);
                return;
            }
            dfs(node->left);
            dfs(node->right);
        };
        dfs(root);
        return res;
    }

public:
    bool leafSimilar(TreeNode* root1, TreeNode* root2) {
        return leafValues(root1) == leafValues(root2);
    }
};
```

## 复杂度分析

### 时间复杂度：**O(m+n)**

`m`、`n` 为两棵树的节点数

### 空间复杂度：**O(n+m)**

## 总结 / 错误反思

优化后的代码有这样的优点：

- 封装性强：将 “**收集叶子值序列**” 的逻辑封装在 `leafValues` 函数中，若其他场景需要生成 “叶子序列”，可直接调用 `leafValues`，复用性更好
- 职责更清晰：`leafValues` 专注于 “生成序列”，`leafSimilar` 专注于 “比较序列”，符合**单一职责原则**，代码组织更**模块化**
- 代码更 “现代”：使用 C++ lambda 实现[[递归]]（尾递归风格），逻辑内聚在 `leafValues` 内部，无需暴露额外的类成员函数

## 知识补充

`auto dfs = [&](this auto&& dfs, TreeNode* node)`中`this auto&& dfs`表示自己调用自己，因为lambda函数没有名字，就只能这么用了
