[二叉树中的伪回文路径](https://leetcode.cn/problems/pseudo-palindromic-paths-in-a-binary-tree/)
## 题目拆解 / 题意分析

节点值只会从 1-9 中选，可以用数组维护出现次数。路径长度可能是奇数，也有可能是偶数，想要满足“伪回文”，就是说要么每个数只能出现偶数次；或者只有一个数出现奇数次

那既然我只关心奇偶性，那就不需要关心具体的数值，可以用一个九位二进制数，依靠[[位运算]]来记录这个数的出现次数，1 为奇，0 为偶。我们在[[长度为 3 的不同回文子序列]]中做过很相似的事

## 解题思路

dfs + [[递归]] + [[位运算]]：dfs先序遍历[[二叉树]]，同时用掩码记录数字出现次数的奇偶性

## 代码实现

```cpp
class Solution {
public:
    int pseudoPalindromicPaths(TreeNode* root, int mask = 0) {
        if (!root) {
            return 0;
        }
        // 按位异或更新奇偶性
        mask ^= 1 << root->val;
        if (!root->left && !root->right) {
	        // 证明见下文
            return (mask & (mask - 1)) == 0;
        }
        // 递归累加左右子树满足条件的路径
        return pseudoPalindromicPaths(root->left, mask) +
               pseudoPalindromicPaths(root->right, mask);
    }
};
```

### 时间复杂度：**O(n)**

### 空间复杂度：**O(n)**

## 总结 / 错误反思

记录有限数据的二元性质时，可以考虑适用位运算

## 知识补充

关于`return (mask & (mask - 1)) == 0;`的解释：

- 如果掩码 mask 中只有一个 1，那么它一定是 2 的幂；将它减去一，它会从“一个 1 后面接很多 0 ”变成“一个 0 后面接很多 1 ”，将这两个结果进行按位与运算一定会得到 0
- 如果掩码 mask 中全是 0，则也是一样的道理
