[出现次数最多的子树元素和](https://leetcode.cn/problems/most-frequent-subtree-sum/)
## 题目拆解 / 题意分析

边界条件是到空节点返回 0，这样一来如果是叶子节点，返回的值就是自身的值（加上 0 等于没加），然后左子树和加右子树和加根节点值，一直向上，直到最上面的根节点

## 解题思路

[[递归]] + dfs + [[哈希表]]：在自底向上的过程中遍历[[二叉树]]，计算子树和，因为要找到次数最多的，所以还需要一个哈希表记录出现次数，同时因为可能出现次数相同的结果，还需要一个变量记录最大次数

## 代码实现

```cpp
class Solution {
private:
    unordered_map<int, int> cnt;
    vector<int> ans;
    int mx;

public:
    vector<int> findFrequentTreeSum(TreeNode* root) {
        auto dfs = [&](this auto&& dfs, TreeNode* node) -> int {
            if (!node) {
                return 0;
            }
            int sum = node->val + dfs(node->left) + dfs(node->right);
            mx = max(mx, ++cnt[sum]);
            return sum;
        };
        dfs(root);
        for (auto& [v, c] : cnt) {
            if (c == mx) {
                ans.emplace_back(v);
            }
        }
        return ans;
    }
};
```

### 空间复杂度：**O(n)**

## 总结 / 错误反思

一开始我在判断边界条件时，想着是“碰到叶子节点返回”，写了一个

```cpp
	if(!node->left && !node->right){
		......
	}
```

但是实际上，在递归中，叶子节点的计算依赖于其空子节点返回 0，才能得到自身的值。而且不深入到空节点的话，递归步骤中的 “当前节点值 + 左子树和 + 右子树和” 将不统一
