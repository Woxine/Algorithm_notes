[对链表进行插入排序](https://leetcode.cn/problems/insertion-sort-list/)
## 解题思路

[[链表]] + 插入排序：插入排序的思想就是，遍历元素，在左侧维护一个已经排好序的部分（下文中称为序列），判断右侧元素是否需要插入左侧

```cpp
class Solution {
public:
    ListNode* insertionSortList(ListNode* head) {
	    // 错误检查
        if (head == nullptr) {
            return head;
        }
        ListNode dummy(0, head);
        // sorted 维护序列
        auto sorted = head;
        auto curr = head->next;
        while (curr) {
	        // 不需要插入，直接扩展序列
            if (curr->val >= sorted->val) {
                sorted = sorted->next;
            } else {
	            // 插入合适位置
                auto pre = &dummy;
                while (curr->val >= pre->next->val) {
                    pre = pre->next;
                }
                // 此时 pre->next 指向序列中第一个大于 curr->val 的位置
                sorted->next = curr->next; // 将 curr 从原位置移除
                curr->next = pre->next;    // curr 指向 pre 的后一个位置
                pre->next = curr;          // pre 指向 curr，完成插入
            }
            curr = sorted->next;
        }
        return dummy.next;
    }
};
```

### 空间复杂度：**O(1)**
