[从链表中移除在数组中存在的节点](https://leetcode.cn/problems/delete-nodes-from-linked-list-present-in-array/)
## 解题思路

[[链表]] + 无序集合：遍历然后去重，注意头节点也可能要删除，所以需要哨兵节点

```cpp
class Solution {
public:
    ListNode* modifiedList(vector<int>& nums, ListNode* head) {
        unordered_set<int> s(nums.begin(), nums.end());
        // 结构体中定义的构造函数
        ListNode dummy(0, head);
        // 取 dummy 对象的地址
        auto curr = &dummy;
        while (curr->next) {
            auto nxt = curr->next;
            if (s.count(nxt->val)) {
                curr->next = nxt->next;
            } else {
                curr = nxt;
            }
        }
        return dummy.next;
    }
};
```

## 复杂度分析

### 时间复杂度：**O(n+m)**

其中 n 是 nums 的长度，m 是链表的长度

### 空间复杂度：**O(n)**
