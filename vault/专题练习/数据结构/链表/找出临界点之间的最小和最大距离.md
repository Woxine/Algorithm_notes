[找出临界点之间的最小和最大距离](https://leetcode.cn/problems/find-the-minimum-and-maximum-number-of-nodes-between-critical-points/)
## 解题思路

[[链表]]：可以确定的是，最大距离一定是**第一个极值点**与**最后一个极值点**之间的距离；最小距离则需要不断更新**当前极值点**与**上一个极值点**之间的距离

```cpp
class Solution {
public:
    vector<int> nodesBetweenCriticalPoints(ListNode* head) {
        int i = 0, first = -1, pre = -1;
        // 因为默认返回为 {-1, -1} 所以最小值初始化为 -1，不然应该是个比较大的值
        int minDistance = -1, maxDistance = -1;
        ListNode* curr = head;
        while (curr->next->next) {
            // y 是要考察的点
            int x = curr->val, 
	            y = curr->next->val, 
	            z = curr->next->next->val;
            // 判断是否为极值点
            if (y < min(x, z) || y > max(x, z)) {
                if (first == -1) {
                    first = i;
                }
                if (pre != -1) {
	                // 因为初始值为 -1，所以不能直接上 min 函数
	                // 否则会一直是 -1	                
                    minDistance = minDistance == -1 ? i - pre : min(minDistance, i - pre);
                    maxDistance = max(maxDistance, i - first);
                }
                pre = i;
            }
            curr = curr->next;
            i++;
        }
        return {minDistance, maxDistance};
    }
};
```
