[两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)
## 解题思路

链表：因为节点数量可能为零，涉及到对头节点的操作，所以需要添加哨兵节点；整个过程是自底向上的，重复执行某一套操作来实现的，运用了迭代的思想（画个图就清楚了）

```cpp
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
	    // 每次操作涉及到 4 个节点
        ListNode dummy(0, head);
        ListNode* pre = &dummy;
        ListNode* curr = head;
        // 确保有两个节点可供交换
        while (curr && curr->next) {
            ListNode* nxt = curr->next;
            ListNode* nxtNxt = nxt->next;

            pre->next = nxt;
            nxt->next = curr;
            curr->next = nxtNxt;
            
            pre = curr;
            curr = nxtNxt;
        }
        return dummy.next;
    }
};
```

### 时间复杂度：**O(n)**

### 空间复杂度：**O(1)**
